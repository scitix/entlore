## This Week's Work

This week, the data collection capability for jynbase, PubChem, Wexops, and IQVIA was finished across 4 websites. Related collection work for PubChem, Tarniver, Wexops, and IQVIA brought structured ticket fields together with unstructured literature capture. Grace Sawyer supported the effort by sorting crawler sources and documenting the main field mappings and anti-crawling approaches. All 4 projects were delivered, with technical review completed and README materials prepared to support regular updates going forward. In parallel, Feishu data research and Falthorne development reached the full end-to-end flow; Falthorne also handled HttpOnly / Secure constraints and produced collected data in JSON. Separately, recall optimization for 100 million records continued after the ISBN and unique identifier matching design, with work now focused on accurate filtering for publisher labels science / literature / philosophy and the first batch of label filtering.

## Next Week's Plan

Next week, the team will finish the quororova matching implementation and check the output quality. Feishu work will move from JSON post-processing into usable data structures. The team will also start Dingxiangyuan data collection.
