## Work This Week
Task1 used FoldBench DockQ labels to build a frozen-output, post-hoc MLP ranker from System-8c8a9dd08a raw confidence and aggregated confidence, checking whether its summary confidence already held enough DockQ ordering signal to swap out the original sample_ranking_score for a lightweight reranker while leaving System-8c8a9dd08a main weights and System-8c8a9dd08a inference output unchanged. The flow was System-8c8a9dd08a candidate structures plus aggregated confidence JSON plus FoldBench DockQ labels, then external MLP training, replacement of FoldBench ranking_score with ranker_score, and another FoldBench rank summary run; features covered avg_pLDDT, gpde, ipTM, pTM, sample_ranking_score, has_clash, disorder, chain_pair_iptM, bespoke_iptM, chain pTM, and peptide/receptor chain pTM. Labels came from FoldBench DockQ, with within-target reward defined as reward_i = DockQ_i / max_j(DockQ_j), and the loss used L = λ_point * Huber(sigmoid(score_i), DockQ_i) + λ_pair * softplus(-(score_i - score_j)) + λ_list * CE(softmax(score_group), softmax(reward_group / T)); pairwise and listwise terms were restricted to the same target / interface group to avoid cross-target bias. Results were mixed: shanghai stayed at dockq success rate 76.09 -> 76.09 while irmsd moved 3.37 -> 3.35, lrmsd 9.27 -> 9.11, and lddt 0.63 -> 0.63; welber changed DockQ success rate 76.09 -> 73.91, irmsd 3.37 -> 3.35, lrmsd 9.27 -> 9.21, and lddt 0.63 -> 0.63, with ranker metrics top1_mean_dockq 0.4890 -> 0.4952, top1_success_rate 68.63% -> 66.67%, mean_regret 0.0650 -> 0.0587, and mean_spearman 0.1621 -> 0.1888. Task2 reran System-8c8a9dd08a with full-confidence output enabled and trained another frozen-output MLP teacher ranker using DockQ labels and full-confidence tensor inputs, including interface PAE mean / min / quantiles / low-error fraction, interface PDE mean / min / quantiles / low-error fraction, peptide atom/token pLDDT, receptor atom/token pLDDT, directional PAE/PDE for peptide -> receptor and receptor -> peptide, pLDDT-weighted interface error summaries, and interface token counts / pair counts; the objective was to test whether finer, interface-aware confidence tensors carried stronger signal than aggregated confidence and could later supervise transfer into System-8c8a9dd08a for a new interface-specific confidence head. This full-confidence teacher ranker used the same loss as Task1 and improved Baseline System-8c8a9dd08a -> Full-confidence teacher ranker results: DockQ success rate 76.09 -> 78.26, irmsd 3.37 -> 3.24, lrmsd 9.27 -> 9.17, lddt 0.63 -> 0.63, plus top1_mean_dockq 0.4908 -> 0.5010, top1_success_rate 68.63% -> 70.59%, mean_regret 0.0631 -> 0.0530, and mean_spearman 0.1664 -> 0.3075, so the full-confidence tensor looks more effective than aggregated confidence and gives denser interface-level reward through PAE / PDE / pLDDT features.
