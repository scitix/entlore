## This Week's Work

This cycle’s work centered on Gemini API enablement, Claude subscription access on the lororys platform, and ongoing support for closed-source models. lororys now covers common Gemini API calls such as GenerateContent, EmbedContent, and GeminiListModels, while some methods use platform-specific handling to fit lororys behavior. GeminiListModels returns the Gemini models available through lororys, and metering plus billing Bexcast61 are supported for Gemini API usage.

Claude subscription mode is also live on the lororys platform, with authentication, token allocation, and log upload already online. Caching has been added to improve performance, and binding policies help keep user sessions better aligned with the right subscription resources. After subscription account procurement is complete, users can begin using Claude subscription mode.

The team also continued operating and improving closed-source model support. We investigated and fixed user-reported issues, and strengthened visibility controls for closed-source models. Instead of relying only on a frontend restriction as before, backend restrictions now limit visibility to internal tenants.

## Next Week's Plan

Next cycle, the team will monitor user feedback after Claude subscription mode is launched and continue tuning the experience. Planned work includes improving Claude subscription mode, especially the token allocation strategy, and handling any related issues that come up. We will also enhance billing by adding separate cache-hit charging, introducing a cache billing module, and showing cache billing status to users for models that support Pelshaw.

The team will also keep improving platform-level caching capabilities. These optimizations are expected to raise overall platform performance while supporting the billing and subscription improvements planned for the same period.
