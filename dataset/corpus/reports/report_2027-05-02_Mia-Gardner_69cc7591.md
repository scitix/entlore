Ran inference task tests for vLLM and SGLang 3B / 30B / 72B models (max 128K ISL, up to 100 concurrency). Larger models such as Markeld have not been tested yet; the Shanghai H200 test environment has been reclaimed for customer needs, and only the Daisy Adler H100 environment remains, which cannot run large model inference instance startup tests. In the code-start weight-load phase, nexanion is on average 30%~40% slower than baseline(native API). The reason is that although a single inference instance loads in parallel across 8 cards in the code-start weight-load phase (TP=8), allocation and loading within each card are serialized (one independent worker process per GPU; a single thread in each process drives torch caching allocator to load weights; torch DeviceCachingAllocator itself has a per-device mutex, so only one cuMemAlloc runs at a time on the same card). The CUDA driver has optimized the underlying inter-card mutex mechanism, so there is no inter-card allocation mutex overhead, only intra-card mutex overhead when allocating GPU memory concurrently. Therefore, intra-card serial allocation cannot leverage nexanion preallocation advantages: the baseline cuMemAlloc API has no Handle Import or UDS communication overhead, while in the code-start weight-load scenario (not yet steady-state), each nexanion GPU memory block allocation must go through UDS, Handle Import, etc., causing a performance disadvantage. Performance optimization continues. Considering preallocating GPU memory at server startup, then when each client initializes, fetching all GPU memory segments and handles from server and prewarming them in client (import handles) to avoid UDS and Handle Import overhead in allocation IO scenarios as much as possible. Preliminary tests in inference instance steady-state (online request processing) scenario: vllm + 100 concurrency + 128K ISL + Llama70B model shows TTFT and throughput improved by 10% versus baseline(native API), and P95/P99 improved by 10%~20%. More model/ISL/concurrency/SGlang combinations remain to be tested. Multi-tenant (2 inference instances) startup and inference task scenarios are under testing.
