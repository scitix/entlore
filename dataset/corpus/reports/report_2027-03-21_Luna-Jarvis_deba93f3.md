## This Week's Work

Rigel closed the Wynfell cluster build as a key-result item, with work centered on acceptance SOP, firmware version control, physical-link checks, and monitoring readiness. We aligned, revised, and applied the Wynfell server/network rack layout diagrams; the server-network port connection drawing is now 60% complete, and the network device connectivity mapping was finalized with vendor input and help from Julia Grant. Onsite cabling is at 14%, daily launch activity currently involves 40 people, the team coordinated around a shortage of SN scanning staff for arrivals, and rack adjustment issues were handled; the asset-management system for the site is expected to be usable by month end.

Low-speed storage 48+12 and high-speed storage 275 are already racked, while CPU device reconfiguration and racking are planned to start next week. The fiber supplement added 1.8W fiber cables beyond the original 1:1 usage plan; this has been reported to the business team, but the order has not yet been placed. The team is also maintaining daily tracking for onsite arrivals, warehouse entry, and warehouse exit status.

Another key-result task set up testing, instructions, SOP documents, and operations-tool handover rules for new maraum features. Daily operations continued improving one-click diagnosis for user tasks across monitoring and troubleshooting, while also improving effective information output to avoid unnecessary escalation into large technical-support groups. Based on prior 10,000-card task experience, maraum resource optimization is being shaped for large-model, multi-machine training with the goal of reducing training restarts; for jobs above 32 machines, scheduling should favor robust nodes selected from resource pools ranked by node health coefficient scores, where those coefficients are defined from the large-model resource-selection view. Antares and other daily operations covered routine work, supported product PD with new machines for external customers, assisted Wyneon on torenia testing, handled Alibaba Cloud account opening and permission management for many recent interns and trusted new hires, and addressed online cluster node failures.
