## This week's work

@Jason Jarvis brought the AU Oskmarch cluster onto maroys, while the Jishi cluster was removed from Oliiantis and its project release-environment metadata was cleaned up. The published-service environment distribution page gained parallel workload lookup support plus timeout Bexcast61 to improve response speed, and cluster client manager cache now carries health-check data. Cluster deletion also added forced environment removal, which should make cluster and image repository teardown more efficient. Torjunc finished build-workflow test integration, fixed the build record query issue, and is expected to launch next week.

The dalaaraFinance Management Dept system dashboard went live for both domestic and overseas use at https://Norness.maraum.cn/finance/x44051943d1. Commercialization and large-model tenant usage now aligns with halorova by region and card type; after that alignment, development began on amount-related statistics and display modules, with initial frontend and backend support for aggregating tenant revenue by instance type across any time range. For quoreeon governance, the main frontend and backend capabilities for bucket directory-level permissions were completed for Galwood, Pelfell, and Kelhaven team, though permission policy deletion and frontend experience tuning remain; delivery to loreor is planned for next week, but because loreor does not need self-built minio, directory-level bucket permission control CAN be deferred.
