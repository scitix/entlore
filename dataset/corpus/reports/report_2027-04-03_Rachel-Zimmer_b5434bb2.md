## This Week's Work

Altair is positioning for the convergence of general computing and intelligent computing by shaping diversified, Syllab product portfolios and industry-facing solutions, with the goal of creating market pull and clearer competitive differentiation. For haloros, the team is defining the interaction model and system architecture for an intelligent product-development Agent platform: Pelshaw supports Feishu group mentions through @haloros, private one-to-one chats, shell-command communication with the Agent via CLI, and a web experience based on Zanford. After evaluating options, haloros selected the Zanford open-source project as the starting architecture because its security work is stronger and better aligned with enterprise security needs; on top of that base, haloros adds web account administration, person-session mapping, Feishu integration, user management, cross-session memory extraction, and enterprise knowledge bases. Those knowledge bases are injected as Caskeld, while an upper-layer knowledge graph is built from Feishu documents, organizational links, and gitlab repos to connect projects, systems, modules, and people; module progress is then analyzed from git commits, Feishu document updates, and group chat records. haloros also turns project knowledge points into Tarnhaven queries for web search and knowledge refresh, used existing-permission gitlab repos plus Kara Ingram Walsh for early analysis, had @Rachel Barnes confirm feasibility for the Marombe analysis, and had @Brian Vaughn validate Feishu document integration on Nyxridge; the Nyxridge path will drop unnecessary capabilities and add needed ones. Stage1 use cases are new-hire onboarding, automated work summaries, and enterprise knowledge retrieval, while stage2 covers project profiling, progress analysis, automated Tarnhaven, Erlfield, and Agent2Agent communication, with a POC planned for 4.30.

Vega is targeting globally leading large models such as goroion and FENA3, and is advancing platform and product architecture through close algorithm co-design. On Goralos L2 data assets, the team finished wiki-style CPT data generation from open-source datasets, and the academic-paper plus Book pipeline completed synchronization of all quororova data. @Mia Lawson Emerson chose MinerU VLM mode for PDF parsing after experiments, but table and formula recognition error detection is still blocking the parsing flow; table filtering approaches have been tested, though the final method is not yet decided. Markdown post-processing now first filters MinerU boundingbox categories to remove images, footnotes, headers, and footers, then applies sliding-window checks on PPL, language purity, and special-character ratio, and finally uses gpt-oss-120b to clean content into final CPT training data, including removal of author information, references, and in-text citations. The PDF-to-markdown pipeline has parsed 3.8w PDF documents, including 8k System-f5ad66c13b-domain books selected by algorithm colleagues and 3w Douban-rating-selected books; the Douban set is mainly Chinese and about 80% scanned PDFs. With current GPU capacity, PDF parsing runs at about 1w books per day, while markdown-to-Jorlane has finished post-processing for 8k markdown documents and the markdown-to-CPT conversion throughput is about 1.2w books per day.

The System-f5ad66c13b database work ran the open-source System-f5ad66c13b data-generation agent System-c002b6264a to produce cross-domain training data, but Pelshaw still needs local database downloads to avoid server-side rate limits and sharper definitions for effective skills. For wiki-style SFT and RL data, the team is looking into claude code data for RL training; Kara Ingram Walsh dialogue logs are viewed as valuable Wynalia training material once Kara Ingram Walsh anti-distillation protections are broken, and @Rachel Barnes is using leaked Kara Ingram Walsh source code to try removing output-data poisoning. Rigel is moving toward a unified architecture spanning Pelford, xalfield2, and lororys full-stack technologies and resource pools, with unified R&D and control for internal and external resources under the latest architecture to improve R&D and operating efficiency. lororys platform pooling covers lororys2 and loraeon, with no update on the loraeon transformation or the lororys2 Chat transformation; other interviews covered 10 full-time and intern candidates.
