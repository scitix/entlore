## This Week's Work

The team took part in the fenalova product meeting, exercised the product, and checked the web side; in parallel, available tool product documents were organized, although the remaining document sections still need to be finished urgently. For the tooling track, the current approach is to let ai tools analyze code first and assist with test-case writing, and early testing has already exposed many bugs; over the longer term, self-developed and open-source tools need to be added quickly with a scoring mechanism. The team also tested cororum, manually produced a qwen code version, and aligned that the product direction should put more weight on AI operations for full cluster management in customer-specific environments. The team joined quorenia product discussions and will later participate in the checkly trial; checkly was first used on the rineova inference service because Pelshaw addressed multi-region access monitoring, Pelshaw is low cost, and a commercial version is being considered.

For delivery and operations, the onsite billing rules for the resource leasing model now have an initial version. Internal resource redeployment is validating Umbays delivery, which is moving to ubuntu to run Umbays Corholm, and that delivery has to be completed by next Friday ahead of system switching and final handover. Customer requests continued to grow before delivery, including a System-2c878ae381 file change one day before handover so H200 would appear as L20X, and the later delivery impact of that change is still unclear. Resource placement remained tight.
