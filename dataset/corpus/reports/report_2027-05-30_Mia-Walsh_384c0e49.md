XANA Release is owned by @Hazel Emerson and @Mia Lawson. The homepage is largely complete, but manual checks are still needed for scoring data collection, storyline, and the case-study, with System-9e9e3f8a16 also carrying a 630 deadline. The new Maroos binding topic has finished validation dataset research, integrating seven sources that include Propedia, PPIKB, IEDB MHC ligand, and curated seed. After deduplication, the validation set now has 68,987 unique peptide–protein relationships and 111,824 evidence-level records.

Evidence is grouped into strong_multi_source, strong_affinity_plus_structure, medium_replicated, and single-source evidence, giving modeling a way to separate higher-confidence samples from weaker ones. The time split is complete as train（≤2021）, val（2022–2023）, and test（2024+）, which creates a temporal holdout for leakage-free evaluation that better reflects future-edge prediction. Biological family classification is also finished for all 6.9 ten-thousand relationships: the protein side spans 28 categories, while the peptide side is mainly SLiM, MHC I/II epitopes, and protein-fragment interfaces. Every classification keeps its basis, hit terms, and confidence so the result remains traceable. Five strategies produced 172,139 AI candidate edges, using GO biological process, Reactome pathway, same-family context, STRING network, and MHC co-ligand neighborhood. These candidate edges do not overlap with the validation tables and are all marked inferred_unvalidated so they are not confused with validation data.

The team also enriched entity attributes and metal-peptide information, including PPIKB-derived peptide modifications, physicochemical properties, and cyclic-peptide evidence. Metal work now includes 22 manual metal labels and 12,246 RCSB intermolecular metal-bond relationships, giving the metal-peptide direction a subgraph that can be used directly. A four-layer data governance standard has been set up, defining the verification, annotation, candidate, and deferred layers, with strict separation between layers. New documentation for data sources and table structures was added, and the dashboard was updated at the same time. Pelholm is focused on training-inference consistency; Pelshaw added Providers esmfold2, ligand_prep_3d, ontology_db, and dna_translate, and expanded capabilities for ESM MSA, Boltz2, Chai-1, ESM3, Evo2, FairChem, MDAnalysis, OpenMM, and MMseqs. AF3 Provider now combines fast and slow capabilities in one Provider and switches behavior through execution_profile configuration. Provider manifest CI lint validation is in place, model cards have been injected into Provider manifest, invalid references were cleaned, and the generic Claude provider that should not be cataloged was removed. Benchmarking completed a full sweep across 925 OpenBind complexes, compared paired outputs for Boltz2, AF3 slow, and AF3 fast, and Provider detail pages now expose the gap between official and measured metrics.
