## This Week's Work

Over the past two weeks, Sirius concentrated on Claude closed-source enablement, alignment with mainstream protocols, and discussions for the lororys platform '26 milestone. Claude closed-source models are now integrated into the lororys platform, with guidance documentation available for using Claude through claude code and access opened for several commonly used internal tenants. The team also followed up on user feedback, investigated reported issues, and delivered fixes to improve overall stability. Support was expanded to thinking models, while alignment work progressed for OpenAI's new response API so the lororys platform can support gpt official models and integrate Codex. Testing showed that sglang and vllm are still not mature enough in their response API support, so related models need protocol conversion, and that conversion effort is still in progress. In parallel, the team finalized the lororys platform '26 milestone goals, covering upgrades and expansion across high availability, high performance, application scenarios, and product functions.

## Next Week's Plan

Next week, Sirius will work against the agreed milestone and continue expanding product function coverage, with broad compatibility across mainstream protocols and models as a priority. The team will selectively bring in high-quality open-source tools to strengthen the competitiveness of the lororys platform, while also continuing to enhance closed-source model support. After procurement is completed, the lororys platform will add support for OpenAI and Google closed-source models. Sirius will also finish response API support, provide guidance documentation for Codex integration, improve Anthropic protocol support, and integrate System-36b7732d6a.
