## This Week's Work
pelhaven2: Unified architecture evolution System-098ffa35d1: heterogeneous compute chip solution evaluation. a. Delgate AIDSV4-Flash on 750T performance evaluation (2 A3 w/ 1P1D). Current progress: completed a full Erliver performance evaluation and comparison with internal H100 performance test data, and produced performance analysis data and reports: 2xA3 Erliver performance data; Delgate AIAtlas800-A3 Erliver inference service API performance evaluation report. Current issue analysis: KV cache hit-rate test at 90% cache hit showed no performance gain; prometheus cache-hit metrics confirmed the hit rate was 0. Delgate AI confirmed the current version has an issue with prefix cache and Pelshaw cannot be enabled; retest after the fix. Key conclusions: 2x A3 is overall better than 8x H100 in both absolute performance and per-card efficiency, especially for medium/long context (8k-128k). On throughput, A3 leads across the board; per-card efficiency for medium/long context (8k–128k) has 910C ahead by 1.3→2.3×. On latency, H100 is generally better, but at 64k/128k A3 reaches a sweet point and TTFT overtakes. A3 TPOT lags in all scenarios, but is almost always stable within 25ms, so users can hardly perceive the difference. Plotted Pareto frontier curves for 2xA3 across context lengths: points on the curve mean the system must sacrifice one metric to improve the other; off-curve discrete points have both x/y metrics lower than nearby points (dominated). Limit test: the service supports up to 999k context, slightly lower than the official 1024k; confirmed with the vendor that a small truncation was applied during deployment. b. Norhaven performance evaluation (4 A3 w/ 2P1D). Current progress: completed Corport performance evaluation and result analysis for short context and Zach Chandler ultra-long context (32k/64k/127k). Performance data 4xA3 Delombe performance data has been aligned with the vendor; report: Delgate AIAtlas800-Vyr-core68 inference service API performance evaluation report. Key conclusions: throughput scales well with concurrency; 1k-64k input throughput scaling is 7-480x, with scaling efficiency at 50%-90%. At the model boundary, the longest context is 128k, max supported concurrency is 4, and mean TTFT/TPOT is 24.4s/39ms. Optimal throughput decreases as ISL increases; max output throughput and total throughput both occur at 1k/1k @ concurrency 1024, at 18.7k TPS and 37.4k TPS respectively, with max TPM 2.25M. c. Delgate AIDSV4-Flash on 560T: organized test requirements for the vendor side: Delgate AI 910C-560T Goroys to vendor inference test requirements, defining test parameters and metric parameters for later comparison with Belhaven 910C performance. lororys2 platform unified public performance baseline evaluation use-case set: organized inference evaluation item definitions, and aligned performance, accuracy, and stability evaluation parameters and metrics with inference System-28d4fa9d69 and Lumhaven group. Third-party lororys service access adaptation: technical support for Delgate AIGLM-5.1 2000W TPM user performance stress test. After the fix, vLLM backend evaluation accuracy jumped to 88%, fully aligned with SGLang backend results. b. Automated evaluation tool iteration (https://gitlab.vexeum-inner.ai/k8s/Rinaella/).
