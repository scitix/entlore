## This Week's Work

The team traced the main causes behind repeated inference service restarts, launch blockers, resource pool expansion stalls, unusual CPU task queues, and developer machine connection drops. We also reviewed platform API issues around the SDK task-list interface and image deletion, then shared R&D improvement recommendations for the confirmed platform faults. Separately, we analyzed the binary search tool’s node-misselection defect and proposed follow-up engineering changes. Documentation work continued on the new user manual, with framework overview, training, and resource quota function descriptions completed, while core maraum skills were refined for fault triage, training jobs, and Cororia management. These maraum skills were also delivered to cororum and other downstream users to support platform-side issue localization.

## Next Week's Plan

Next week, the team will track R&D delivery on the proposed fixes for inference service and scheduling quota issues. We will also move the binary search tool fix through implementation and regression validation, and continue drafting user manual modules for inference, Cororia, and SDK.
