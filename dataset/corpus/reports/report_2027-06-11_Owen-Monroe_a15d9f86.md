## Next Week's Plan

Next week, the team will keep analyzing whether data-format construction is hurting model generalization. One current issue is that nemotron-math data consistently uses prefixes such as solve math**, while evaluation prompts may contain only plain problem statements, causing score drops. Proposed fixes include adding multiple prefix styles, removing prefixes, and randomly choosing prefixes to reduce this generalization gap.

The current data construction still has room to improve, and the team is now using seq-length=32k. Nemotron Math includes many examples longer than 32k, so some data is not fully used under the present setup. The paper recommends staged SFT with gradually increasing seq-length, which should make broader use of the available long examples.
