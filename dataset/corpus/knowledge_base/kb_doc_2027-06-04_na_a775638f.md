- The automatic install did not progress past Installing.
- KVM access out of band showed the installer had crashed.
- The crash was tied to the hard disk not being mounted.
- Insert the hard disk before retrying the deployment.
- Record whether the machine has 1 hard disk or 2 hard disks installed.
- Reinstall after confirming the disk count and placement.

- After completion, the network still could not be reached.

## Troubleshooting steps
- Used `ethtool bond0` to review link speed; the normal reference is 50000Mb/s.
- The check pointed to an incorrect port binding.
- Ran `ip a` to identify the other network interface names.
- `ethtool ens9f0np0 |grep Speed` returned Unkown for ens9f0np0.
- The bonding interfaces should be ens9f0np0 and ens9f1np1.

## Continue checking other network interface speeds
- Continued the review by checking speed values on the remaining interfaces.
- ens3np0 and ens2np0 both showed active speeds.
- Updated `/etc/netplan/bond0.yaml` so netplan used ens9f0np0 and ens9f1np1.
- Retested the gateway ping, and network connectivity returned to normal.
- After installation was complete, the node stayed in Completed state.

## BMC login to view network card information
- Logged in through BMC to inspect the network card details.
- Reviewed the bond0 settings and found the two configurations did not match.
- The probable issue was misidentification during bond0 interface binding.
- Adjusted the bond0 configuration manually.
- Ran `netplan apply` so the update would take effect.
- After the change, the bond port came up.
- Gateway communication was confirmed as OK.
- The node state returned to PingCompleted.
