# Pelfell cluster GPU Stress Test Report

| Item | Summary |
|---|---|
| Acceptance scope | GPU stress acceptance for the Pelfell cluster covers 256 nodes. |
| Node inventory command | An ansible command is provided with `k8s_all_node.list` and `gpu_all` to collect every node’s `bond0` IPv4 address and hostname. |

The acceptance workflow starts with `dalanent` to diagnose the health state of the nodes, then moves into GPU-node communication checks. After communication is validated, the single-machine large model workload is run with `llama2-13b` from `large_language_model_pretraining_test.tar.gz`. For H100/H200 nodes, the pass line is an average result of 480+, while H20 nodes are accepted at 120+ on average. The multi-machine large model stage uses `llama2-70b` with the same `large_language_model_pretraining_test.tar.gz` package, so the workload sequence stays consistent across the large model checks.
