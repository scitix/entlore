# Dorholm cluster node expansion IPoIB configuration and GPFS client node addition SOP
## Configure IPoIB
- Scope: Dorholm expansion steps for IPoIB setup and adding GPFS client nodes
- Use `/etc/netplan/bond0.yaml` as the baseline config on newly expanded nodes
- Set the new node Ethernet address to `10.94.125.222/24`
- Align the IPoIB address as `90.168.97.244/22`
- Keep the IPoIB conversion fixed; the subnet mask must remain `22`
- Add the `ib0` IP settings in the newly highlighted block
network:
  version: 2
  renderer: networkd
  ethernets:
    ens9f0np0:
      addresses: []
    ens9f1np1:
      addresses: []
  bonds:
    bond0:
      interfaces:
        - ens9f0np0
        - ens9f1np1
      addresses:
        - 10.94.125.222/24
      routes:
        - to: 0.73.135.100/0
          via: 10.36.182.246
      parameters:
        mode: 802.3ad
        mii-monitor-interval: 100
        transmit-hash-policy: layer3+4

## Add nodes to the GPFS Client Cluster
- Run `netplan apply` to bring the IPoIB configuration into effect
- After applying netplan, verify that the IPoIB settings match the expected values
- In Holgrove, go through Cluster Products and Node Management
- From Node Management, choose the region and the `Oraport(vexadm)` cluster
- Change the node storage status to `Initial`
- Setting `Initial` starts the add-node task again for the GPFS Client Cluster
- Treat the GPFS client addition as done once storage status shows `MountFSCompleted`
network:
  version: 2
  renderer: networkd
  ethernets:
    ens9f0np0:
      addresses: []
    ens9f1np1:
      addresses: []
    ib0:
       addresses: [90.168.97.244/22]
    ib1:
       dhcp4: no
    ib2:
       dhcp4: no
    ib3:
       dhcp4: no
  bonds:
    bond0:
      interfaces:
        - ens9f0np0
        - ens9f1np1
      addresses:
        - 10.94.125.222/24
      routes:
        - to: 0.73.135.100/0
          via: 10.36.182.246

        mode: 802.3ad
        mii-monitor-interval: 100
