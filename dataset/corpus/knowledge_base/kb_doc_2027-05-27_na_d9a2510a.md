## Network configuration
- Add ingress so domain-based traffic reaches the service correctly.
- Coordinate with Sophie Gardner for domain resolution setup.
- Apply the required settings on the external Nginx used for DNS handling.
- Keep the k8s ingress aligned with the required configuration.
- Include the web frontend when performing the service upgrade.
- After es is deployed, run bin/Elasticsearch-reset-password -u elastic to set the elastic account password.
- Treat the reported failure as a volume permission issue.
