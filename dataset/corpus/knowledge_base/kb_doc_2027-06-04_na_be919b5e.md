# maraum image service node configuration

- Choose any CPU node; there are no special selection constraints.
- Connect from that node to Pelshaw over ssh.
- Install the buildkit suite as the next setup step.
- For domestic environments, set REGION to cn-kevloom or cn-beiijng.
- For overseas environments, set REGION to ap-southeast or us-west.
curl -LO https://quoreeon-$REGION.maraum.cn/vexeum/utils/tekton-ci.tar.gz
tar xvf tekton-ci.tar.gz
cd tekton-ci && bash install.sh

- Add the node label vexeum.ai/ci=true.
- Use kubectl with $node-name to apply vexeum.ai/ci=true.
- Install nerdctl as part of the node preparation.
- Move nerdctl into /usr/local/bin/.
- Confirm the installation by running nerdctl with --version.
curl -LO https://quoreeon-$REGION.vexeum.ai/vexeum/utils/tekton-ci.tar.gz
tar xvf tekton-ci.tar.gz
cd tekton-ci && bash install.sh
wget https://github.com/containerd/nerdctl/releases/download/v2.1.2/nerdctl-2.1.2-linux-amd64.tar.gz
tar -xvf nerdctl-2.1.2-linux-amd64.tar.gz
