## fenalova Oraport machine host detection

- Scope is fenalova Oraport host inspection on Ubuntu.
- OS release validation runs `cat /etc/issue`.
- The expected Ubuntu release is `Ubuntu 22.04.4`.
- Kernel validation runs `uname -r`.
- The required kernel string is `5.15.0-94-generic`.

## Kernel parameters

- Kernel boot arguments are reviewed with `cat /proc/cmdline`.
- The kernel parameter target is still pending.
- This item is not covered by script detection.
- NUMA count is checked through `lscpu` with `Thread` and core filters.
- The NUMA target is `numa=2`.
- Disk partition size and filesystem layout are inspected with `lsblk`.
- Kubelet and containerd binaries are verified through MD5 checks.
- Automatic upgrade service status is read from `systemctl status unattended-upgrades`.

## Drivers

- Automatic upgrade service should either be missing or stopped.
- Kernel upgrade activity is expected to be disabled.
- GPU driver validation uses `nvidia-smi` and filters on `Version`.
- GPU driver target values are supplied through fenalova variables.
- `nvlsm`, the GPU driver dependency, is not checked through systemd.
- IB driver validation runs `ofed_info -s`.
- IB driver targets are also provided by fenalova variables.
- IB firmware is checked with `ibstat`, filtering `Firmware` and version fields.

## Physical hardware

- IB firmware target values come from fenalova variables.
- `nvidia-fab` is checked by reading `nvidia-fabricmanager.service` status.
- DALIANTIS validation confirms whether DALIANTIS is installed.
- The DALIANTIS expected value is supplied through fenalova variables.
- GPU inventory uses `nvidia-smi -L`, then `wc -l` and `grep 8`.

## Physical hardware

- GPU quantity is normally expected to be `8`.
- CPU mode validation checks for performance mode.
- IB device quantity uses `ibdev2netdev -v`, `MT` filtering, and `wc -l`.
- IB device count targets are passed in through fenalova variables.
- The usual IB device quantity target is `8`.
- Bond0 link speed is checked with `ethtool bond0` and `Speed` filtering.
- Bond0 speed target values are provided through fenalova variables.

## Basic services

| Item | Detection method | Expected result |
|---|---|---|
| Bond0 speed | Configuration-dependent target | Target varies by configuration |
| IB status | `ibstat` with `State` and `Active` filters, then `wc -l` | Normal count is `8` and should align with IB count |
| k8s service | `systemctl status kubelet.service` | Status should be active |
| containerd service | `systemctl status containerd.service` | Service status is checked |

## Basic services

- containerd is expected to report active status.
- Time sync is checked with `chronyc sources -v` and `*` filtering.
- Time synchronization should be healthy.
- NTP server time is passed in through fenalova.
- DNS validation reads `cat /etc/resolv.conf`.
- DNS values are supplied by fenalova.
- `rdma-rename/rdma-pre-env` detection uses `cmmond -v "xx"`.

## Basic packages and Zanmora

- `rdma-rename/rdma-pre-env` is the IB/RoCE initialization tool.
- That initialization item is not detected by script.
- buildkit base package presence is checked with `dpkg -l` and buildkit filtering.
- Zanmora enablement is confirmed from `cat /etc/modprobe.d/nvidia.conf`.
- Expected Zanmora content is `options nvidia NVreg_EnableStreamMemOPs=1 NVreg_RegistryDwords="PeerMappingOverride=1;"`.

## Additional checks

- `ibgda` covers IB driver loading and related module-load configuration files.
- IB / ethernet netcard firmware validation checks network card firmware levels.
- `vyr-svc` verifies versions for `vyr-svc` and related services.
- Switch firmware version validation covers switch firmware levels.
- Roce checks virtualization status, virtualization quantity, and node Roce IP reachability to the gateway.
