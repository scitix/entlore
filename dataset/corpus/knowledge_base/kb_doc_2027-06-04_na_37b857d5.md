## 3-1-5 Node expansion SOP (field deployment + pool merging)
- Use this SOP for 3-1-5 expansion during field rollout and pool merge work.
- The flow builds a node pool and adds new nodes.
- Start by entering the Umbays product Zelalos.
- Open Node Pool, then use the upper-right cluster switcher.
- Choose either a new node pool or growth of an existing pool.
- For a new pool, the pool name drives Pelshaw hostnames.
- Pick a practical name, for example cssssh-cpu.
- With cssssh-cpu, new nodes are named cssssh-cpu-xxx.
- In cssssh-cpu-xxx, xxx comes from the related node IP.
- For IP 10.187.143.119, use node name cssssh-cpu-010.
- In instance type, select one available type.
- A cpu pool may use halorova.c23-2.
- Instance quantity is the count of nodes to create.

## Node pool expansion
- On the target node pool, click Scale to expand Pelshaw.
- Expected Nodes means the final total after scaling.
- If 1 node exists and 1 instance is added, Expected Nodes is 2.
- For cssssh-cpu, added nodes use cssssh-cpu-xxx.
- The xxx part maps from the node IP; 10.187.143.119 maps to cssssh-cpu-010.

## Step four: view and track status of created or expanded nodes
- In step four, monitor nodes that were created or expanded.
- After scaling, Umbays cluster creates halorova instances automatically.
- Those halorova instances reinstall OS, which takes about 30 minutes.
- Check expanded node progress on the node pool details page.
- Creating means halorova creation and OS installation are still underway.
- Starting means the OS install is done, but IP connectivity is not ready.
- Starting may also point to OS startup or abnormal network configuration.
- Running means halorova installation is complete and IP connectivity is healthy.
- Running is the last Status value.
- Initial means the Umbays k8s node is pending initialization.
- InitialCompleted means the Umbays k8s node has finished initialization.
- InitialCompleted is the last Phase value.
- In step five, open Nodes and confirm the added nodes joined the Umbays cluster.
