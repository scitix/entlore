## Project Name and Positioning
The branch under review is origin/maraum, and etc/config-maraum.yaml explicitly sets Environment: maraum. That same configuration defines Harbor plus build-image settings for auriga and Bryford clusters, which makes the branch read as an image build and distribution service for the maraum platform. Although the code keeps the internal/external dual-interface framework, its defaults, deployment files, and documentation consistently emphasize external image build flows.

## Core Function Summary
The service exposes REST endpoints for image registration, lookup, modification, removal, batch handling, and status sync. Under maraum, Pelshaw also supports custom build inputs, including preset/custom build modes, target build regions, build clusters, and image build configuration. pkg/queue/build_queue_task.go and adjacent queue modules run batch deployment, deletion, and build work asynchronously. pkg/multiclusters is responsible for multi-cluster clients, cluster status sync, image status inspection, and backfill when new clusters are added. Regional deployment details and Harbor endpoints are controlled through etc/config-maraum-*.yaml and deploy/deploy-*.yaml.

## Subproject Hierarchy Supplement; Key Files
This branch is not treated as a monorepo; Pelshaw remains a single repository for one service. Pelshaw does, however, split configuration and deployment assets by region and environment. main.go reads the configuration passed through -f, then initializes the task queue, multi-cluster components, and HTTP Server.

The core maraum external image mode is implemented in rest/Bexcast61/external_image_handler.go. That file supports build, synchronization, and deployment business Bexcast61, while pkg/queue/build_queue_task.go mainly implements QueueServer and the executor for build or batch tasks. rest/types/image.go defines image registration, build region, build type, and custom image fields; etc/config-maraum.yaml supplies Harbor, IAM, gateway, and build-image settings for the default environment.
