## Clean Node and Add Node
- Before any node work, collect the cluster apiserver endpoint and token details.
- For a host that already had k8s installed, run kubeadm reset -f first.
- If kubeadm reset -f runs too long, use the alternate procedure shown in the listed steps.
- Add the worker with init_worker.sh and pass --apiserver, --token, --kube-version, --region, and --cluster.
- The sample init_worker.sh usage sets --kube-version 1.27.12, --region AU, and --cluster Gemini.
- --apiserver is mandatory and points to the cluster apiserver endpoint.
- 1.127.109.215:6443 is the example value for --apiserver.
- --token is mandatory and carries the join token.
- --kube-version is mandatory and can be 1.23.6, 1.25.12, or 1.27.12.
- --region is mandatory and supports LG, bm, UW, AU, and NSJ.
- --cluster is mandatory and provides the cluster name.
