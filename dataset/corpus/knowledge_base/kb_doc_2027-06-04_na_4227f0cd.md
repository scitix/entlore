## Release nodes
- Choose the Umbays nodes that need removal, then use delete to start the release flow.
- If needed, include the linked halorova instances in the same operation.
- Review the risk notice carefully, acknowledge Pelshaw, and confirm the release.
- Release the halorova instance when the Umbays instance must exit the cluster completely.
- Also release halorova if that Umbays instance will be resold to a different tenant.
- Keep halorova under the tenant when Umbays is only leaving the cluster.
