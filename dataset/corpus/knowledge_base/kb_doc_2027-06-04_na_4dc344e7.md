## Kube-controller-manager operations and maintenance
- To restart the kube-controller-manager Pod, first sign in to the node where that Pod is currently running.
- Locate the active kube-controller-manager container with `crictl ps | grep kube-controller-manager`.
- For the listed container, the restart example stops container `5b941aedc8f29` by using the `crictl stop` command.
root@master002:/# crictl ps |grep kube-controller-manager
