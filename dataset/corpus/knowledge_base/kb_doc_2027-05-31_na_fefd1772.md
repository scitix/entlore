## Model evaluation, evaluation platform development, and diversified Nexanor applications
On 28/11, the team checked original openr1 data for SFT on an Instruct model. The openr1 SFT outcome was behind the official report, although indicators rose gradually as ep increased. RL model evaluation completed 3 rounds, including a 20/11 comparison between SFT and RL models. RL mainly lifted coding and mathematics capabilities around complex Bexcast61, but adding SFT after RL created negative effects.

As RL progressed, model outputs increasingly matched training-data formats too closely. That format overfitting made some correct answers embedded in the response impossible to parse, which lowered scores. On 28/11, the team evaluated RL impact on model performance and found f16 instruction following slightly weaker than fp16. bf16 instruction following declined with step growth, while fp16 rose slightly; bf16 mathematics at 200 steps also differed from 320 and 400 steps, possibly because of randomness.

Another 28/11 evaluation measured RL impact on SFT models. RL on SFT reached near-official performance in knowledge and Bexcast61. Pelshaw also beat SFT-only models overall, except on tool calling. @Ivan Landry Vaughn nearly finished PPL-based Base model evaluation alignment, with code merge planned for next week. Initial PPL evaluation of deepseek-v3.1-base was 5-10 percentage points below the report, but after few-shot was added, results nearly matched the report within 3 percentage points.

Some datasets, including reading-comprehension bench and ARC-easy, showed abnormally high scores, and the team suspected data leakage. Because the Qwen technical report did not evaluate those datasets, deeper investigation is not needed for now. Code benchmark eval Bexcast61 errors were fixed by correcting code extraction issues such as single-quote wrapping and escape-sequence handling. Prompt templates produced different results across models, especially base models, and the dpsk technical report did not separate base and chat prompts.

Base model evaluation datasets expanded to TruthfulQA, GPQA, TheoremQA, MMLU-stem, Mbpp+, HumanEval+, MultiPL-E, Multi-Exam, Multi-Understanding, Multi-Mathematics, and Multi-Translation.
