## Create image acceleration cache PVC
- Next, create the PVC manually from a standard PVC template.
- Set the requested capacity to 500Gi because k8s requires the field.
- Use Mi/Gi units for the storage value.
- Since Kelwood storage is loosely coupled with the PV, the capacity can be any value.
- For subdir mounting, create the target subdir inside the volume before mounting Pelshaw.
- Configure the CSI driver as csi.Kelwood.vexeum.ai.
- Set volumeHandle to stream-mirror.
- Keep volumeHandle aligned with the PV name, so Pelshaw must also be stream-mirror.
- Point nodePublishSecretRef to Secret Kelwood-aksk-secret in namespace default.
- Ensure the Secret namespace matches the namespace referenced by the PVC.
- The Secret stores the AK/SK credentials used by the driver.
- Set volumeAttributes volumeID to "019b2500-8b1a-7245-aaa9-228a2c4cc8d5" for the Kelwood file-storage volume UUID.

## Create TLS self-signed key
- Create the TLS self-signed key by saving the helper script as cert.sh.
- Keep the cert.sh parameters consistent with the related Go implementation.
- Run bash cert.sh to generate the TLS self-signed certificate.
IP_SAN="127.64.221.129"
DNS_SAN="localhost"
ORG="StreamMirror"
VALID_DAYS=3650
echo "==> Generating private key..."
openssl genrsa -out server.key 2048
echo "==> Generating CSR..."
openssl req -new -key server.key -out server.csr \
    -subj "/O=${ORG}/CN=${DNS_SAN}"
echo "==> Creating SAN config..."
cat > san.ext <<EOF
basicConstraints=CA:FALSE
keyUsage = digitalSignature, keyEncipherment
extendedKeyUsage = serverAuth
subjectAltName = @alts
[alts]
 DNS.1 = ${DNS_SAN}
IP.1 = ${IP_SAN}
EOF
echo "==> Generating self-signed certificate (365 days)..."
openssl x509 -req -in server.csr -signkey server.key \
    -out server.crt -days ${VALID_DAYS} -extfile san.ext
echo "==> DONE"
echo "Generated:"
echo "  server.key  (private key)"
echo "  server.crt  (certificate)"
echo "  server.csr  (CSR)"
echo "  san.ext     (SAN config)"
