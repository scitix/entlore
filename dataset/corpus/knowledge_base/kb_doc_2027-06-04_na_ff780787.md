## Add nodes to a dynamic node pool
- Use a dynamic node pool to add, remove, and schedule nodes.
- One-click fast allocation between two clusters is available only for nodes in a dynamic node pool.
- For batch addition, choose the cluster, then its node pool, then the nodes within that pool.
- After addition, the page displays the dynamic node list.
