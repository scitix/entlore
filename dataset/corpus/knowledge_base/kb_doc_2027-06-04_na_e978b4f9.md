# Configure CI build node

- Pick any cpu node; there are no special placement requirements.
- Connect to Pelshaw over ssh from the selected node.
- Install the buildkit suite as the next setup step.
- For domestic deployment, set REGION to cn-kevloom or cn-beiijng.
- For overseas deployment, set REGION to ap-southeast or us-west.
- Verify buildkit health with `systemctl is-active buildkitd`.
