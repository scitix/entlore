## Mount
- Run mount.DALIANTIS-NFS for DALIANTIS-03010301.03010301-001.<region>.NFS /scratch to /mnt/<mountpoint>.
- Use options vers=4.1, hard, retrans=2, timeo=600, and noresvport.
- The manual also covers automatic mount behavior after a compute-node restart.
mount -l | grep NFS

## Alert
### Troubleshooting
- After restarts, compute nodes may not mount automatically.
- The Quorum node relies on crontab for recurring mount checks.
- nfsd_down means the NFSD process is stopped.
- The same alert shows that the NFS server is not running.
- Run the troubleshooting commands from the Quorum node.
grep NFS-scratch /etc/fstab

## Troubleshooting
### Repair method
- Check node flags from the Quorum node.
- A node flag shown as none is healthy.
- A node flag shown as failed is an error state.
- centaurus107 is the abnormal NFS server to repair.
- Suspend <abnormal node name> with mmces node suspend --stop.
- Resume <abnormal node name> with mmces node resume--start.
- The repair is complete once every node flag returns to none.
/usr/lpp/mmfs/bin/mmces node list
