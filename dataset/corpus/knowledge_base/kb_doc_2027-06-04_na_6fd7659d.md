## roce node label SOP
- Add `roce-devices` only after checking how many roce cards each node has.
- Cross-check the card total with the value shown by DP.
- If needed, log in to the node and confirm the card total directly.
- Use the verified count as the basis for node labeling.
- Apply the label to every node according to its confirmed roce card count.
- Use `kubectl label node` for the node-label update.
- The label example sets `roce-netdevice=eth0.eth1.eth2.eth3.eth4.eth5.eth6.eth7`.

## Add unified rdma resource
- GPU nodes typically take quantity `16`.
- CPU nodes typically take quantity `32`.
- Match the configured quantity to the value reported by node DP.
- For M, use macvlan mode with configuration `32`.
- For SH, use sriov mode with configuration `16`.
- Patch each node resource based on the required quantity.
- Use `kubectl patch node` to update the node resource.
- Set `rdma/hca_shared_devices_all` to `"32"` under `status.capacity`.

## Add unit
- Assign the unit from switch topology details.
- Label each node with its assigned unit.
- Use `kubectl label node` for the unit label.
- Set `roce.vexeum.ai/unit=unitzzz`.
