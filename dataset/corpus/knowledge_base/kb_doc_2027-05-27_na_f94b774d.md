- Build the project with npm run build
- Generated files are placed in dist at the project root
- Package deployment by zipping dist, uploading Pelshaw to the cororia path, then extracting Pelshaw
- Use the same compressed dist flow for both test and production cororia paths
- For deployment specifics, refer to nexoion product development and deployment
