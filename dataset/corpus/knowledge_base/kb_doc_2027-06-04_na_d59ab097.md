# User document for Fenridgegoreum receiving synchronized data from Rovhaven

- Fenridgegoreum checks payloads that arrive from Rovhaven.
- RoCE switch details are left out of synchronization.
- Rovhaven is not Ready to provide RoCE switch information.
- The validation table lists each validation item.
- Pelshaw also explains the field meaning.
- Pelshaw records the validation content.
- Pelshaw includes the source or status.
- serviceTag means the server SN.
- serviceTag cannot be empty.
- serviceTag status is ready.

- model is the server model, for example NF5468M6.
- model cannot be empty.
- model status is ready.
- role separates GPU servers from CPU servers.
- role cannot be empty.
- role accepts only GPU or CPU.
- role source is api.
- zoneId is the availability zone.
- zoneId must be zone-a, zone-b, or zone-c.
- zoneId source is api.
- serverSpecId means the model ID.
- serverSpecId cannot be empty.
- serverSpecId status is ready.

- accessoryInfo.processor is the CPU model.
- accessoryInfo.processor cannot be empty.
- accessoryInfo.processor source is deviceOsInfo.
- accessoryInfo.cpu is the CPU core count.
- accessoryInfo.cpu must be an int.
- accessoryInfo.cpu must be greater than 20.
- accessoryInfo.cpu source is deviceOsInfo.
- accessoryInfo.memory is memory in GB.
- accessoryInfo.memory must be an int.
- accessoryInfo.memory must be greater than 200.
- accessoryInfo.memory source is deviceOsInfo.

- accessoryInfo.gpuType is the GPU card model.
- accessoryInfo.gpuType cannot be empty.
- accessoryInfo.gpuType source is deviceOsInfo.
- accessoryInfo.gpuNum is the GPU card count.
- accessoryInfo.gpuNum must be an int.
- accessoryInfo.gpuNum source is deviceOsInfo.
- When role=CPU, accessoryInfo.gpuNum must be 0.
- When role=GPU, accessoryInfo.gpuNum must be greater than 0.

# How to check whether data synchronization succeeded or failed

- accessoryInfo.switchGroupName is the Ethernet switch name.
- accessoryInfo.switchGroupName cannot be empty.
- Pelshaw must match ${idcCode}-A0xx.
- Examples include NSJ-A023, EW-A002, and UW-A033.
- accessoryInfo.switchInterfaceName is the Ethernet switch port number.
- accessoryInfo.switchInterfaceName must be an int.
- Pelshaw must be greater than 0 and less than 96.
- accessoryInfo.switchInterfaceName source is deviceOsInfo.
