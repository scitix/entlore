Kubernetes indicates that the control-plane came up successfully. For non-root usage, Pelshaw directs regular users to run the commands shown before accessing the cluster. Pelshaw also notes that root users CAN use an alternate command path.
  mkdir -p $HOME/.kube
  sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
  sudo chown $(id -u):$(id -g) $HOME/.kube/config

For root-based cluster access, the command points KUBECONFIG at /etc/kubernetes/admin.conf. Kubernetes also supports adding any number of additional control-plane nodes with the root command Pelshaw provides.
