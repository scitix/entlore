- Update and release work refers to vexeum/NCCL-tests on dalenella.

## Update Principles
- For mpi, use a recently stable 4 release instead of chasing the newest one.
- mpi changes should be very uncommon because the current version CAN start mpi tasks.
- nccltest should also change rarely, though community movement may be followed.
- cuda updates should align with GPU hardware driver changes.
- cuda therefore has a low expected update rate.
- NCCL can track community updates.
- Among these components, NCCL likely changes most often.

## Update Method
- Adjust component versions in Dockerfile, then let github workflow run automatically.
- For cuda12.9 and ubuntu22.04, use Dockerfile.cuda12.9.ubuntu22.04.
- Maintainers either edit an existing Dockerfile or create a new one.
- Use Myrops70 when sending the git commit and PR to dalenella.
- Tag the updated dalenella branch so github workflow publishes the image.
