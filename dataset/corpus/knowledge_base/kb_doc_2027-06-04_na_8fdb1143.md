## SOP for Beijing and kevloom environments accessing Alibaba Cloud quoreeon over private network

- Scope is Beijing and Shanghai access to Alibaba Cloud quoreeon through private networking.
- Corkeld uploads to public-cloud quoreeon currently run through privatelink.
- privatelink bridges the cloud quoreeon 100 segment and the off-cloud 10 segment.
- Forwarding through privatelink still creates traffic charges.
- The discounted estimate for 100PB traffic is about 35w.
- The current off-cloud to cloud dedicated line can replace privatelink after setup.
- With Alibaba Cloud configuration, IDC networks can reach cloud quoreeon directly; internal Pelshaw does not need to operate Pelshaw.
- Alibaba Cloud built a 10-segment service mapped to the quoreeon 100-segment service.
- The 10 segment must be allocated from the cloud vsw so Pelshaw does not collide with off-cloud IP ranges.
- Alibaba Cloud supplies regional resolution domains for 10-segment IPs and wildcard domains.
