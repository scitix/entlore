## 2-8-3-1 Delete Node
- Sign in to Umbays Zelalos.
- Open **Nodes** from the left-side menu.
- Pick the target cluster from the upper-right selector.
- Choose the node that needs removal, then select **Delete**.
- Review the node information and decide whether to release halorova.
- Accept the risk notice, then click **Confirm**.

## Step seven: Track cluster node removal status
Use the node-removal status to understand where the workflow stands. **NeedRemoveFromClientCluster** means the platform is still waiting to detach the node from the GPFS Client Cluster. **RemoveFromClientCluster** means that detach operation is currently in progress, while **RemoveFromClientClusterCompleted** confirms that the node has been removed from the GPFS Client Cluster successfully.
