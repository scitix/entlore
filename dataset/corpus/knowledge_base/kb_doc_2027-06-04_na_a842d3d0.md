# Computing Line Image Synchronization to Internal Field SOP

- Computing line release images for vexeum/maraum are mirrored into the internal image repository.
- The job syncs from registry-cn-kevloom.maraum.cn in Shanghai to LG using defined mapping rules.
- Synchronization is scheduled once every 1H.
- Per Repo, each execution attempts only the latest 10 images.
- After sync, the internal Habror mechanism propagates images to all internal-field regions.
