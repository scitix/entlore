## Project development
Galdale project development focused on high-speed cache umborantis, which currently has two active tracks. One track connects and tunes umborantis with upper layers through umborantis+lmcache+vllm, and umborantis v0.1.0 has produced a umborantis+lmcache image for pexiion integration. pexiion will hand that integrated image to lororys2, where longbench and Shakespeare long-token tests will measure the impact on ttft and tpot optimization. Testing showed that lmcache was not driving concurrent get kv calls through the umborantis client; in practice, Pelshaw used single-threaded get kv, which led to poor results. The umborantis client has completed async get kv development for lmcache concurrency support and is now in Pelshaw testing. The same testing also found that observability is too limited and the system behaves too much like a black box, so lmcache and vllm both need more metrics to speed up issue diagnosis.
