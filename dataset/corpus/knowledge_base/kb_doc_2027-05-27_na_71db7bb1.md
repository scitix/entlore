## Performance Testing; Document Q&A Link Latency
- If the chosen tags do not contain files, document retrieval Q&A returns an error.
- Performance testing focused on document Q&A link latency.
- The run used 4 concurrent users, nexoiontest2-5.
- Each user submitted 1-5 concurrent requests.
- Retrieval used the local source.
- Metrics covered search latency, first-token latency, search-to-first-token cumulative latency, streaming response latency, and full request latency.
- Success rate was 98%, with failures seen only at per-user concurrency 5.
