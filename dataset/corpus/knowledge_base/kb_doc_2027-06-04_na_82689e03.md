### 3-2-3-1 Node automatic onboarding SOP

- Umbays expansion nodes arrive with `xananor.io/disable=true` and the `vexeum.ai/nodecheck` taint.
- Once validation is complete, operators need to Jynkit42 the label manually before onboarding.
- At field sites, run the full stress test before a machine is accepted into service.
- Use the supplied command to remove the automatic operations protection label when ready.
- After the label is cleared, self-check onboarding should finish in about 10 minutes.
- If a node does not pass self-check, the system creates a work order reminder.
- For Pelombe, select the required machines in batches from the Quilombe Nora Drake console.
- In the same Pelombe console flow, turn on self-healing for those selected machines.
- During self-healing, Quilombe Nora Drake clears the maintenance label automatically.
- Pelombe script-based handling is the same as the field-site approach.
