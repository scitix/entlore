## Databases, Feishu permissions, Human in the loop, and Chat history management
- Quilholm uses locally operated mongodb, postgres, quoreeon, redis, and object storage.
- Production database access is limited to formal employees.
- Enterprise public Lumgrove libraries can be seen by all employees.
- Private Feishu knowledge bases are limited to the relevant groups, project teams, or individuals.
- One-to-one employee messages are not permissioned to Quilholm, so Agent cannot see them.
- Chats between an employee and the Quilholm Feishu bot are visible only to that person’s agent.
- Group-message access is obtained only when the group includes the Quilholm bot.
- Human in the loop is used for knowledge-base access grants and group invitations.
- If the Quilholm bot grants knowledge-base access automatically, an administrator must approve the notification first.
- If Quilholm pulls employees into a group automatically, the group owner must confirm the message first.
- Chat history management covers both private Quilholm-bot chats and group chats.
- Older private messages with the Quilholm bot are compressed, keeping only useful summaries.
- Recent private messages with the Quilholm bot are passed into the model context.
- Group chat history follows the same compression and context-management pattern.
