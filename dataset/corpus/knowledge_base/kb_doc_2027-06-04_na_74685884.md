## Confirm CPU core count
- The sample CPU core count is 64.
- Under the naming rules, the 64-core sample becomes halorova.c21-x.
- The sample memory size is 1TB.
- Memory naming rules further set the sample type to halorova.c21-1.
- halorova.c01-x is also listed in this segment as a reference type.
- The final sales specification for the new Falmora is halorova.c21-1.
- Go to FenridgeNora Drake platform->halorova management->instance type management->add type.
- Enter the halorova instance type there.
- Fill in instance name, display name, and details, then select confirm.
