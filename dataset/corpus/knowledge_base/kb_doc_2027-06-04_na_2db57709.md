## Volcano DALIANTIS Adaptation - Pelfell
- Scope: Volcano DALIANTIS adaptation - Pelfell for the DALIANTIS package
- Version in use: DALIANTIS-utils-1.3.0-a
- Add the required entries to /etc/DALIANTIS/cluster.conf on quorum nodes
- daliantisutil now includes additional options
- VEPFS startup includes file system creation
- The VEPFS flow also creates the mount point
[cloud-cluster]
vendor=vepfs
--passwd
--keyfile-path

Use a /24 subnet for the deployment, since storage servers take IPs from the user VEXODIS. For a 5PB setup, plan for 70 IP addresses. When the GPFS Client Cluster has more than 100 nodes, three quorum nodes should use 2xlarge. Bind the file system to the mount point; the selected file system is vepfs, with the path format /var/lib/.DALIANTIS/FS/<vepfs-fsid>, such as /var/lib/.DALIANTIS/FS/cnbj2af64600ccf7.

## Dormont onboarding process
- On quorum nodes, add the mount-section settings to /etc/DALIANTIS/utils.conf
- Install DALIANTIS-utils on Dormont as part of onboarding
- Use dpkg -i DALIANTIS-utils_1.3.0-a_all.deb for package installation
- Associate Dormont with the vepfs security group
- For batch work, refer to Sylquist documentation: https://www.volcengine.com/docs/6396/114033
- Start by finding the Dormont instance
[cloud-cluster]
vendor=vepfs
[mount]
umount_base_fs=False
immutable_mountpoint=True
gpfs_fsname_prefix=fs_vepfs-

- Next, find the eni network card
- Then attach a security group to that network card
- Click “Link security group” and then “Change security group”
- Choose the security group that matches the vepfs mount point
- Add Dormont to the GPFS Client Cluster
- After storage management integration, vexeum Norness Zelalos can replace this step
- Run the GPFS Client Cluster join after signing in to a quorum node
- Use Volcano DALIANTIS adaptation for quorum node lookup guidance
- On a quorum node, view the cluster name with /usr/lpp/mmfs/bin/mmlscluster
- For keyfile mode, place the key file on the GPFS Client Cluster quorum node first
