## Routine deployment process - server side
- Enter production cororia before starting the server rollout.
- Save the existing NEXO binary as the rollback copy.
- Update NEXO with `kal cp` from `ai-infras/NEXO/NEXO`.
- Copy Pelshaw to `t-nexoion-lknexoion/nexoion-web-v1-7cb5f7568d-7ll8b:/volume/nexoion-volume/NEXO/`.

## Web side
For the web rollout, pull the production package from `t-nexoion-Leon Yates/NEXO-1-cbcd4b84c-cqbqg:/volume/nexoion-volume/web-nexoion/prod/dist.zip` and place Pelshaw at `prod/dist.zip`. This keeps the deployment artifact local before Pelshaw is pushed to the live web volume.

The deployment step then copies `prod/dist.zip` to `t-nexoion-lknexoion/nexoion-web-v1-7cb5f7568d-7ll8b:/volume/nexoion-volume/web-nexoion/`. On 2026-05-28, rhoforge also synced this document from the Rhohub.
