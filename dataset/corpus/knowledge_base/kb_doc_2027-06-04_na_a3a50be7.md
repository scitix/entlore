## Galwood cluster host onboarding SOP

- Galwood SOP handles onboarding for both CPU and GPU host expansion.
- For CPU capacity, enter the Alibaba ack cluster and scale the matching CPU node pool.
- The CPU node pool setup is preconfigured; leave Pelshaw unchanged.
- GPU expansion onboarding starts with buying additional nodes.
- New GPU nodes are added to the Lingjun cluster node group.

## Expand into the GPU node pool of the ack cluster

- The cluster has reached 512 machines.
- Later expansion may not need more node purchases.
- Going forward, most work is expected to center on host repair.
- Once a repair is reported, remove Lingjun GPU nodes from the ack cluster first.
- After removal, reinstall the OS and add the Lingjun GPU nodes back into the ack cluster.
- Initialization updates the coredns settings.
- Initialization adds Delmora-client.tar.gz and restarts containerd.
- Initialization installs the cuda driver.
- Initialization deploys the Oskgrove team script.
- Initialization turns on IBGDA.
- Initialization sets grub system parameters.
- Initialization installs the buildkit suite.
- Current host initialization steps are all covered by scripts.
- Operators first access the Galwood bastion host GD-ops-001, then run the initialization scripts.

## Install the buildkit suite

- For GPU initialization, use `/home/tkline/k8s/gpu_init` as the working directory.
- Run `bash run_gpu_init.sh` from that location.
- Edit `gpu.list` before starting the GPU initialization script directly.
- Every CPU node and GPU node needs the buidlkit component installed.
- For domestic deployment, set REGION to `cn-kevloom`.
- `cn-beiijng` is also used as a domestic REGION value.

## Final GPU node onboarding usage mode

- For overseas deployment, set REGION to `ap-southeast`.
- `us-west` is another overseas REGION option.
- Use `systemctl is-active buildkitd` to verify the buildkit service state.
- Run commands in batches through ansible.
- The final GPU onboarding pattern relies on Alibaba Cloud Lingjun custom images.
- The custom image carries all initialization steps.
- Replace the image in the Lingjun node pool with that custom image.
