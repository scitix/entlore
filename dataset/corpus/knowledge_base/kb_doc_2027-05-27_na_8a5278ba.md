# nexoion General Agent Design - Competitor Research - Manus

- This research reviews Manus as a reference competitor for nexoion’s general-purpose Agent design.
- Manus is available at https://manus.im/.
- Task execution is broken into visible steps, with returned content expandable by step.
- Users can open detailed task information during execution.
- Generated files are versioned throughout the workflow.
- If step 1 and step 2 both change file A, Manus can compare the live contents.
- Files can be previewed while the task is still running.
- Code blocks are shown with syntax highlighting during execution.
- Executed commands are presented in bash format.
- A progress panel at the bottom lets users jump between steps involving file edits or commands.
- Browser search results can be displayed and previewed.
- Standard results appear as lists, while image results are shown as cards.

- By default, Manus opens computer task details from a Dovnet floating panel near the input field.
- Manus can produce a summary covering every file created during the run.
- Clicking the file summary opens a popup with the full generated-file list.
- Generated assets are grouped as all, documents, images, code files, and links.
- Coze Space is available at https://www.coze.cn/space-preview.
- Compared with Manus, Coze Space uses a more streamlined interface.
- Coze Space does not expose task steps.
- Selecting a file in Coze Space brings up task details in a drawer on the right.
- Coze Space includes an area for summarizing output files.
- Its output-file summary is not split into categories.

# nexoion Feature Design

- nexoion supports uploading files.
- Upload support also needs to cover Feishu documents.
- One option is to reuse the knowledge base add-file UI for Feishu document upload.
- nexoion supports file preview while work is in progress.
- Document previews should include formats such as pdf and md.
- Image previews should cover items such as process screenshots.
- Code preview should handle py, js, Oraport, and html.
- Link previews should include web links accessed during the process.
- The intended visual result should be close to the referenced effect diagram.
