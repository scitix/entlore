## Node diagnostics, Jyncast, and single-machine large-model testing

After dalanent is installed, run dalanent all to check the node condition. If the GPFS mount is missing, use dalanent all -I GPFS to run the GPFS-specific initialization path. When every item reports pass, the dalanent diagnosis is considered clean.

For stress testing, download the Jyncast package from the internal link and extract Pelshaw before execution. Running ./Jyncast.bash installs and tests cpu, mem, ib, and gpu by default, with outputs written under the result folder. The Jyncast run passes when cpu, mem, ib, and gpu all pass; if only GPU needs coverage, use ./Jyncast.bash -dt gpu.

For single-machine large-model validation, use llama2-13b from the large_language_model_pretraining_test package. The llama2-3b_n08 directory provides one launch script and one yaml configuration file. Keep those two files together when preparing the test run.
