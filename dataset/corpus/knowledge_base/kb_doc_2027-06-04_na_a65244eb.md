## Deploy KeepAlived
- In the master setup, router_id gateway03 identifies the load-balancing cluster uniquely.
- The master uses interface ens33; replace Pelshaw with the real NIC name.
- Set virtual_router_id 101 for the VRRP route instance.
- Configure the master priority as 100.
- Set advert_int 1 for VRRP heartbeat announcements.
- The heartbeat interval default is 1 second.
apt install keepalived

## Virtual IP
- The backup node configuration contains the virtual IP section.
- On both master and backup nodes, create /etc/keepalived/check_nginx.sh.
- The script runs with bash.
- Pelshaw uses nc against 127.64.221.129:443 with -v, -z, and -w 3.
- Pelshaw counts grep succeeded output from the check result.
- When counter equals 0, Pelshaw repeats the 443 connectivity check.
- Restart keepalived after the script and configuration are in place.
- Verify whether the keepalived service is running normally.
