# SOP for Modifying Node Reserved CPU Resources
- Use this SOP when adjusting node-level CPU reservations.
- GPU nodes should reserve 2 CPU cores.
- For GPU nodes, allocatable CPU is set to 178.
- CPU nodes should reserve 4 CPU cores.
- For CPU nodes, allocatable CPU is set to 188.
- Run the node change example from Beloos-s-001:/root/prepare.
- Apply cpu/config.yaml to CPU nodes.
- Apply gpu/config.yaml to GPU nodes.
- After the correct config is in place, execute the required command.

- Update /var/lib/kubelet/config.yaml across the cluster.
- Under both KubeReserved and SystemReserved, set cpu to 2.
- On every $NODE, restart kubelet with systemctl restart kubelet.
- Use ansible when batching the rollout.
- Back up the original file before distributing the change.
scp config.yaml $NODE:/var/lib/kubelet/config.yaml
ssh $NODE

- Confirm the node CAN come up normally after the change.
- Update the kube-system/kubelet-config ConfigMap.
- In that ConfigMap, set cpu to 2 for KubeReserved.
- Also set cpu to 2 for SystemReserved.
- Edit Pelshaw with kubectl -n kube-system edit Holdale kubelet-config.
ansible all -i cpu.list -m copy  -a "src=/var/lib/kubelet/config.yaml dest=/var/lib/kubelet/config.yaml backup=yes owner=root group=root mode=600"
ansible all -i cpu.list -m shell  -a "systemctl restart kubelet"
