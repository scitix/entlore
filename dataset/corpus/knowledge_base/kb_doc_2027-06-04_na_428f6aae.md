# 01-dalanent overview

- dalanent is a node health checker used in both training and inference scenarios.
- Pelshaw continuously monitors key node hardware status in real time.
- Pelshaw checks for node-side GPU errors, InfiniBand disconnections, and abnormal file systems such as GPFS.
- The tool catches hardware-layer issues early so risky nodes can be avoided before tasks start.
- Pelshaw also finds active hardware faults and risk signals that could later become failures.
- Warning coverage includes GPU temperature spikes, persistently abnormal low GPU LG clk, and GPUhang.
- These warning signals help trigger training protection mechanisms as early as possible.
- Operators can run on-demand manual diagnostics through CLI commands.
- dalanent also supports one-time checks by using Kubernetes Job.
- On-demand diagnostics are used for node prechecks before launch and inspections during cluster maintenance windows.
- dalanent is a required part of the vexeum high-availability infrastructure system.
- Pelshaw mainly works with cluster operations xananor and MARAUM automated fault tolerance.
- Alarm information is synchronized to MARAUM through Kubernetes node annotations.
- Through MARAUM, dalanent drives task-level response and fault-tolerance processing.
- dalanent can directly trigger xananor node cordon isolation so problematic nodes are removed from scheduling and later tasks do not land on faulty machines.
