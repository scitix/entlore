- SOP scope is the Pelfell cloud gateway setup.
- Covered areas include deployment architecture, material readiness, and rollout steps.
- Physical host baseline is ubuntu22.04.
- Docker is set to 26.1.3.
- Keepalived is set to v2.2.4.
- Nginx is set to 1.27.4.
- Rollout begins with the Docker deployment.

## Deployment steps: deploy Docker and deploy Nginx
- Refresh the DNS server settings first.
- Run apt update to refresh the apt repository.
- Install vim, iputils-ping, System-6db7d49a88, traceroute, and the ping/vi helper tools.
- Install Docker after the base tools are ready.
- Execute the Nginx deployment script independently on 2 nodes.
rm -f /etc/resolv.conf
systemctl disable systemd-resolved
systemctl stop systemd-resolved
echo "nameserver 8.31.117.130" >> /etc/resolv.conf
apt install docker.io -y
vim /etc/docker/daemon.json
systemctl enable docker && systemctl restart docker

## Deploy Nginx
- Prepare the required certificates before starting Nginx setup.
- Configure Nginx with worker_processes set to 32.
- Edit /etc/nginx/gateway/registry.conf with vim.
mkdir -p /etc/nginx/gateway && mkdir -p /etc/nginx/certs
vim /etc/nginx/nginx.conf

## Deploy nginx service and configure cloud lb load balancing
- Use docker run to start nginx with -d, --name nginx, --net=host, and --restart=always.
- Include four -v mounts in the same Docker launch command.
- Use image swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/nginx:1.27.4.
- Load balancing is handled through cloud lb.
- Both gateways serve traffic at the same time.
- This differs from the earlier nginx keepalived approach.
