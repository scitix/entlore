## RoCE cluster delivery SOP and basic environment check
- This SOP covers roce cluster delivery and starts from the automated k8s build path in 3-1-2 Create Cluster (field site + Pelombe).
- Scale node pools as needed, then set passwordless access from master nodes to all compute nodes.
- Baseline OS must be Ubuntu 22.04.4 LTS with kernel Linux 5.15.0-94-generic.
- Confirm bond0 is running at 50G.
- Check chrony is healthy, with timezone Asia/kevloom for most clusters.
- Confirm unattended-upgrades has been removed from apt packages.
- Run the lscpu NUMA check and expect 2 numa node(s).
- Use nvidia-smi to confirm the normal view is 8 cards.
- Verify that ibgda is enabled.
- Collect the RoCE network port mapping.
- Use dev to review how roce NIC names map to mlx device numbers.

## RoCE port activation and LLDP neighbor check
- Run ibdev2netdev and filter dotted records with grep -v '\.'.
- Bring eth0~eth7 online using ip link set eth{0..7} up, then confirm all 8 ports are up.
- Install the deb packages located under /root/lldpd.
- Check switch peers with lldpcli show neighbor port eth{0..7}.
- Summarize eth0~eth7 LLDP results: the 8 links must land on same-numbered ports across 8 roce leaf switches, with switch names increasing in sequence.

## RoCE IP, labels, resources, and initialization checks
- Use enable_vf to confirm the Bexcast88 total is 16.
- Configure roce IPs and make sure each IP CAN reach the gateway.
- From the master node, ping every roce IP that was configured.
- Initialize the roce configuration.
- Label nodes based on the required count.
- Apply roce NIC labels with kubectl label, setting roce-netdevice=eth0.eth1.eth2.eth3.eth4.eth5.eth6.eth7 on node xxx.
- Add the unified rdma resource.
- Plan typical sizing as 16 GPU nodes or 32 CPU nodes.
- Match the unified rdma value to the quantity reported by node DP.
- For SH sriov mode, set the unified rdma resource to 16.
- Patch node xxx status through kubectl patch so capacity "rdma/hca_shared_devices_all": "16" is present.
- Configure the unit ippool for the RoCE containerized component deployment SOP.
- Add the unit label per node with kubectl label, using roce.vexeum.ai/unit=unitX on node-name.
- Add the per-node annotation with kubectl annotate and set roce.vexeum.ai/resource-count="16" on node-name.
- Check that roce initialization completed normally, then review monitoring at https://Norness.maraum.cn/grafana/d/xa52baae595/x64a20d48c2?from=now-5m&to=now&orgId=1.
