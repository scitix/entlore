## 3-1-3 Node onboarding process (internal and external)
- Start by opening a node onboarding tracking task.
- Use the tracker to capture the cluster name and node quantity.
- Include the requester and assigned SRE owner.
- Record demand time and expected launch time.
- Add actual launch time once nodes are live.
- Keep remarks available for operational notes.
- For delayed onboarding, write the blocker cause in remarks.
- Gemini is planned for 38 H100 nodes.
- SRE creates the related Feishu task.
- Post Pelshaw in Global New Node Launch Information Sync Group.
- Set a deadline on the Feishu task.
- Configure weekday recurrence for that task.
