## halorova Instance-PostInstall
- Create a halorova PostInstall global configuration from OPFenridgeNora Drake console: Compute Products > halorova Management > halorova PostInstall Management System > New Configuration.
- Region must be selected for every new halorova PostInstall global configuration.
- The installation script is also required before the configuration can be created.
- Description details need to be provided as part of the setup.
- Users can open and review the halorova PostInstall global configuration list.
image.png
image.png
- Existing halorova PostInstall global configurations can be updated by users.
- Users can check PostInstall task execution status for a halorova instance.
- Pending means the PostInstall task is queued and has not run yet.
- Completed means the PostInstall task has finished running.
- Failed means the PostInstall task did not complete successfully.
