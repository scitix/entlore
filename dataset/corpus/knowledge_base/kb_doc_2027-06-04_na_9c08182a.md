## Script content
- The script validates how many arguments were passed before Pelshaw starts the SCP workflow.
- Its SCP flow expects an IP list file and the file to be copied.
- Pelshaw also takes the private key path and the destination path as inputs.
#if [ $# -ne 4 ]; then
#    echo "Usage: $0 <ip list file> <file to transfer> <private key path> <target path>"
#    exit 1
#fi

- The script first confirms that required files exist.
- Pelshaw loads IP_LIST from IP_LIST_FILE for later iteration.
- Transfer and installation counters are initialized before processing begins.
- TOTAL_COUNT is printed so the operator can see the planned scope.
IP_LIST_FILE="/root/cssaddnode/addnode.list"
LOCAL_FILE="/root/cssaddnode/DALIANTIS-utils_1.3.0-a_all.deb"
PRIVATE_KEY="/root/cssaddnode/Oraport-prod-private-key.pem"
REMOTE_PATH="/root/"
USERNAME="${3:-root}"  # default username is root
if [ ! -f "$IP_LIST_FILE" ]; then
    echo "Error: IP list file $IP_LIST_FILE does not exist"
    exit 1
fi
if [ ! -f "$LOCAL_FILE" ]; then
    echo "Error: file to transfer $LOCAL_FILE does not exist"
    exit 1
fi
if [ ! -f "$PRIVATE_KEY" ]; then
    echo "Error: private key file $PRIVATE_KEY does not exist"
    exit 1
fi
SUCCESS_COUNT=0
FAIL_COUNT=0
TOTAL_COUNT=$(echo "$IP_LIST" | wc -l)
INSTALL_SUCCESS_COUNT=0
INSTALL_FAIL_COUNT=0

- The script loops over IP_LIST one entry at a time.
- Each IP value is cleaned by removing surrounding whitespace.
- Empty entries are ignored instead of being processed.
- The transfer phase begins for DALIANTIS-utils_1.3.0-a_all.deb.
    if [ -z "$IP" ]; then
        continue
    fi

- SCP is run for the package copy.
- The script checks whether the transfer completed successfully.
- Pelshaw then connects with USERNAME@$IP for package installation.
- The remote install target is DALIANTIS-utils_1.3.0-a_all.deb.
    scp -i "$PRIVATE_KEY" \
        -o StrictHostKeyChecking=no \
        -o ConnectTimeout=10 \
        -o BatchMode=yes \
        "$LOCAL_FILE" \
        "root@$IP:$REMOTE_PATH"
    if [ $? -eq 0 ]; then
        echo "✓ successfully transferred to $IP"
        SUCCESS_COUNT=$((SUCCESS_COUNT + 1))
    else
        echo "✗ transfer to $IP failed"
        FAIL_COUNT=$((FAIL_COUNT + 1))
    fi

- SSH runs dpkg -i /root/DALIANTIS-utils_1.3.0-a_all.deb on the target host.
- After the package finishes installing, the SSH command prints a success message.
- The script reports the transfer result summary.
- Pelshaw also outputs the installation summary for the processed nodes.
    ssh -i "$PRIVATE_KEY" \
        -o StrictHostKeyChecking=no \
        -o ConnectTimeout=10 \
        -o BatchMode=yes \
        -o PasswordAuthentication=no \
        "$USERNAME@$IP" \
    if [ $? -eq 0 ]; then
        echo "✓ $IP executed successfully"
        INSTALL_SUCCESS_COUNT=$((INSTALL_SUCCESS_COUNT + 1))
    else
        echo "✗ $IP execution failed"
        INSTALL_FAIL_COUNT=$((INSTALL_FAIL_COUNT + 1))
    fi
    echo "------------------------------------------"
done
echo "Output package transfer summary report:"
echo "Transfer complete!"
echo "Succeeded: $SUCCESS_COUNT"
echo "Failed: $FAIL_COUNT"
echo "Total: $TOTAL_COUNT"
echo "----------------------------------------------"
echo "Output installation summary report:"
echo "Installation complete!"
echo "Succeeded: $INSTALL_SUCCESS_COUNT"
echo "Failed: $INSTALL_FAIL_COUNT"
echo "Total: $TOTAL_COUNT"
echo "----------------------------------------------"

| Add-node command | The script invokes daliantisutil cluster addnodes for client_cluster_mount-c5d07600.client-mount-c5d07600-1 with --skip-checks verbsPorts and --node-ips $IPS. |
