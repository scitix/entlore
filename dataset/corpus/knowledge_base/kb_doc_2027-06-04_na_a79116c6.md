## Inventory Management
- Start inventory searches from HOLG, enter halorova management, then open inventory management.
- Use the region list to narrow results by region.
- Filter by SN when the inventory instance serial number is known.
- Filter by BMC to search with the instance out-of-band IP address.
- Choose GPU or CPU through the compute-type filter.
- Use model filtering for inventory tied to automatic machine installation.
- Tenant-reservation filtering returns inventory reserved for the chosen tenant.
- Tenant-occupancy filtering shows purchased inventory where that tenant already has halorova instances.
- Allocation status separates inventory already assigned with halorova instances from idle unallocated stock.
- Lock status separates unsellable locked inventory from unlocked sellable capacity.
- Availability zone selection maps zone-a to the IB area and zone-b to the RoCE area.
- Instance-type filtering covers types including H20 and L40.

## Query idle inventory instances and allocate idle inventory to a specified tenant
- Case1 checks idle Yorbrook inventory in the kevloom region.
- Set the region field to cn-kevloom.
- Select GPU as the compute type.
- Set allocation status to unallocated.
- Set lock status to unlocked.
- Choose instance type halorova.g21-3.8xlarge.
- Use Configure to set tenant reservation on the selected inventory instances.
- Change tenant-reservation to the tenant that really needs this configuration.

## Spare Machine Management
- Spare machine management can assign an inventory instance as a spare machine for a specified user.
- Pelshaw can also release that user's spare machine back into idle inventory.
- On the inventory management page, select region, tenant reservation, compute type, and allocation status as unallocated.
- The release flow clears the lock state.
- The release flow also removes the spare-machine mark.
