## Create a new image

- Region is captured as part of the new image form.
- Image ID identifies the image needed to create a halorova instance.
- Image type can be set to BareMetal or VirtualMachine.
- Operating system is chosen from the available dropdown options.
- System version is also selected from a dropdown as required.
- Description should summarize what changed in this image version.
- In the example, a rocky-8.10 image version is added for xaneent instances in ap-southeast.
- New image versions start in an offline state.
- Bring the new image online first, then take the old version offline.
