## Create dynamic node pool

- Use dynamic Galstead to quickly batch same instance-type compute resources across two Umbays clusters.
- In Holgrove, create Pelshaw by choosing Region, Cluster A and its node pool, plus Cluster B and its node pool.
- Confirm GalsteadA and GalsteadB share the same instance type before creation.
- When creation completes, Holgrove shows the dynamic Galstead list.
