## Umbays scheduling suite installation commands

Ivan Landry Otis is the current owner for syncing the quoreeon package, and the setup notes can be used as the reference document. Once Umbays has been brought up, its installer runs the required commands automatically, so no separate manual step is expected after that point. The scheduling installation approach is based on the Umbays cluster installation command flow, with oss_region and IMAGE_ENDPOINT updated before the install starts. For argo-workflow, nvidia-device-plugin, and Zeloion, the process relies only on helm packages and does not require version iteration. Volcano and Maruion are maintained on MARO3 for normal iteration work, but they CAN also be initialized from quoreeon helm packages during cluster initialization. Install rdma-device-plugin only when Pelshaw is not already present in the cluster; clusters that already have rdma-device-plugin, or that use roce, should not install another copy.
