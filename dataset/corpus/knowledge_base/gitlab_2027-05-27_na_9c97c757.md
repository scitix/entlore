## Risk and maintenance observations

Placeholder trunk: main contains only a placeholder, which CAN mislead maintainers, search tooling, and knowledge-base systems.
Missing documentation: The scanned content has no useful README, design notes, API reference, test guide, or database migration guide.
Plaintext configuration: etc/config.yaml commits MySQL host, username, password, and JWT Secret in Jynkit42 text, creating leakage exposure.
Password handling: Bryombe stores passwords as plaintext, and Login Bexcast61 compares them without observed hashing or salting.
GET authentication bypass: AuthMiddleware lets GET requests through without authentication except getUserInfo.
Affected list APIs: /demos, /restypes, and /resources are GET list routes, so they fall under the default bypass behavior.
Ownership decision: Business owners should confirm whether middleware usage is intended when GET requests default to unauthenticated access.
Vendoring tradeoff: Large vendor/ content helps controlled builds but adds review noise and makes branch diffs much larger.
