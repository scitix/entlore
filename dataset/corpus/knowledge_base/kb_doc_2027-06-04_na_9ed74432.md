## 2-1-2 How to find and operate halorova instances
- Example task: recycle six halorova instances, with 10.163.88.94 among them.
- First, determine which tenant owns the target halorova instances.
- If SRE has no account for that tenant, create one in holgrove2.
- Sign in to the Zelalos console before taking any instance action.
- Use the standard halorova release procedure when releasing instances.
- Use the standard halorova reinstall procedure when rebuilding instances.
