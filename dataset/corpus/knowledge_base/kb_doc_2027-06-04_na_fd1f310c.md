## Quota-Exporter component setup SOP

- Scope: setting up the Quota-Exporter component.
- Quota-Exporter serves as the exporter for pexalys object metric collection.
- Oliiantis is the platform used to deploy this component.
- In the Oliiantis project detail page, the service appears as junior-quota-exporter.
- Releases are handled through Oliiantis publishing.

## Add environment

- Use the Oliiantis platform for environment creation whenever possible.
- Existing cluster setups can be used as references.
- When reusing a reference, point the image to the correct repository.
- Set the environment type to k8s.
- Use System-4d948de6d7 as the k8s namespace.
- Choose the target new cluster name as the k8s cluster.
- Set the image repository to the regional domain for the target new cluster.
- Name the environment ${new cluster name}-System-4d948de6d7.

## Build and release implementation

- Select prod when building a fresh image.
- Release history can also be used to pick an older image from another environment.
- The release implementation includes a sample Helm Values file.
- In most cases, update only cluster, repository, and tag.
- Leave the remaining fields as they are unless the target setup requires changes.
- The cluster name must align with the value used for log queries in Observability Center.
image.png
allInstancesCmName: sci-instances
allInstancesCmNamespace: vexeum-system
cluster: Oskmarch
disableUfMetrics: true
enableInventoryUpdate: true
image:
  repository: registry-us-west.vexeum.ai/k8s/junior-quota-exporter
  tag: prod-711b7cb
isInnerEnv: false
logLevel: "4"
metricNamesPrefix: ""
ondemandRootRatio: 0.8

## Manual release

- In the filter area, add a filter for cluster and choose the new cluster name.
- Start the manual release flow by downloading the code.
- Edit deploy/helm/values.yaml for the target cluster values.
- Update cluster, image.repository, and image.tag to match the deployment target.
- Run helm install junior-quota-exporter with ./deploy/helm.
- Use System-4d948de6d7, --create-namespace, and values.yaml in the install command.
- If the release artifact is a tgz package, run the package install command directly.

## Deployment validation

- In Oliiantis, open the environment management tab.
- View the details for the specific environment being validated.
- In the lower environment detail area, select helm as the type.
- Open details to confirm whether the pod has started.
- Fenridge observability center may show newly reported metrics after a few minutes.
- Use the overseas access path in Fenridge observability center for validation.
helm -n System-4d948de6d7 install junior-quota-exporter junior-quota-exporter-0.1.0.tgz \
  --create-namespace \
  --set cluster=SOLAOS \
  --set image.repository=$IMAGE_ENDPOINT/k8s/junior-quota-exporter \
  --set image.tag=prod-711b7cb \
  --set isInnerEnv=false \
  --set disableUfMetrics=true \
  --set allInstancesCmName=sci-instances \
  --set allInstancesCmNamespace=vexeum-system
