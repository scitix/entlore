## Enter the silencing page; write silence rules

- Open the console, then choose new silence from the top-right area.
- Existing silence entries can be modified directly when needed.
- Expired rules can be reopened from Expired and created again.
- Duration controls the active window, for example 2h or 7d.
- Matchers use alert kv fields to decide scope and can include regex.
- Creator should be filled with the operator’s own name.
- Comment should briefly explain the reason for the rule.

## Examples; silence a single alert

- This case shows the setup for muting one specific alert.
- alertname="Faliver" selects alerts carrying that alert name.
- cluster="css2" narrows the match to the css2 cluster.
- Without cluster="css2", alerts with the same name in other clusters would also be silenced.
