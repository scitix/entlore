## Common parameter descriptions and IB network test SOP

- `--allow-run-as-root` lets MPI execute under the root user.
- `--hostfile ./iplist` points MPI to the test node inventory.
- `--map-by ppr:8:node` launches 8 ranks on each node, typically aligned with GPU count.
- `--mca oob_tcp_if_include bond0` routes MPI launch control traffic over bond0.
- `--mca pml ^ucx` turns off the UCX PML path.
- `--mca btl self,tcp` keeps self and tcp active while excluding openib.
- `--mca btl_tcp_if_include bond0` confines TCP transport to bond0.
- `--mca routed direct` selects the direct routing method for MPI rank connectivity.
- `--mca plm_rsh_no_tree_spawn 1` avoids tree spawn so ranks use direct ssh/rsh.
- `-x UCX_TLS=tcp` limits UCX to tcp and removes RDMA from the run.
- `-x NCCL_DEBUG=INFO` sets NCCL logging at INFO level.
- `-x NCCL_MIN_NCHANNELS=32` requires at least 32 NCCL channels, trading more resources for throughput.
- `-x NCCL_IB_QPS_PER_CONNECTION=8` assigns 8 IB QPs per NCCL connection for higher resource use and performance.
- `-x NCCL_IB_HCA` narrows the IB cards NCCL is allowed to use.
- `-b` defines the smallest data size used at the start.
- `-e` defines the largest data size used at the end.
- `-f` controls size growth between steps; the default is 2.
- For `-b 2G -e 16G`, sizes progress as 2G 4G 8G 16G.
- `-n` sets how many iterations run for each size.
- `-N` sets per-size repetitions; default: 1; 0=infinite.
- For the IB SOP, build the `iplist` file on the control node, for example the gateway node.
- Put the hostnames selected for testing into `iplist`.

## IB network physical machine nccltest

- For IB physical-machine nccltest, leave `NCCL_IB_GID_INDEX=0` implicit unless needed.
- Use `allreduce` as the test operation.
- Start by validating a single size, for example 16g.
- Target throughput is above 90% of the combined bandwidth across all node network cards.
- For 4x400Gbps: (200GBps), expect > 180GBps; for 8x400Gbps（400GBps）, expect > 360GBps.

## IB network test continuation and RoCE network test SOP

- `-N 10` runs 10 repeats and returns 10 result outputs.
- Use those 10 outputs to judge whether performance is fluctuating.
- A multi-size run can cover 2G-16G.
- Without that range, the run uses only one size by default.
- Expected throughput is 90% of the node's single-card network bandwidth.
- For 400Gbps: (50GBps), the target is >45GBps.
