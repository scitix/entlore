## Modify Kubelet MaxPods SOP
- Set kubelet maxPods to 220 for the target cluster nodes.
- Save a kubelet-config backup before changing the cluster ConfigMap.
- Use kubectl with KUBECONFIG_PATH for the export.
- Export the kube-system kubelet-config ConfigMap into backup.yaml.
- Switch into the target cluster before editing kubelet settings.

## Operation steps and rollback plan
- Edit the kube-system kubelet-config ConfigMap through kubectl.
- Update data.kubelet so maxPod is 220.
- Restart kubelet on nodes in batches after the config change.
- For Sylflow25 cluster, only node restarts are needed.
- To roll back, restore kubelet-config maxPods to the previous value.
- After rollback editing, restart node kubelet with the same batch process.
