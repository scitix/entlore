## 2-9-1 Image Registry Product Deployment SOP
- For any new region, finish all prerequisite tasks before rollout.
- Deploy Harbor after the preparation work is done.
- Include the Harbor service itself in the deployment scope.
- Enable Metrics by starting the exporter from the Harbor docker compose setup.
- Set up image sync between habor1 and habor2.
- Verify habor1 and habor2 can exchange images as expected.
