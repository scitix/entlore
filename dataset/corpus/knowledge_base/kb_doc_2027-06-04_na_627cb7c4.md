## 6-1-1-3 Storage Cluster Deployment Requirements - Deployment - Network Ports
- GPFS I/O traffic uses TCP 1191.
- The GPFS data path covers compute-to-storage communication.
- The same GPFS I/O path also applies among compute nodes.
- GPFS control traffic uses ICMP.
- ICMP has no port number.
- Control-plane ICMP applies between compute and storage, and within compute nodes.
image.png

- GPFS control traffic uses TCP 60000~61000.
- The TCP control range totals 1000 ports.
- This range applies between compute and storage, and among compute nodes.
- GPFS reset API service uses TCP 80, 443, 11080, and 11443.
- The reset API path runs from the management cluster to storage.
- Monitoring includes a network-port row for 9980, 9981, and 9085.

## Pre-deployment Information and Software Configuration Requirements
- Monitoring uses TCP 9980, 9981, and 9085 for pmcollector.
- The pmcollector path runs between the management cluster and compute or storage.
- Monitoring also uses TCP and UDP 4739 for pmcollector.
- TCP 4739 and UDP 4739 apply between the management cluster and compute or storage.
- Monitoring uses TCP 19100 for node exporter and GPFS exporter.
- TCP 19100 applies between the management cluster and compute or storage.
- Deployment preparation must include the cluster name.
- Rack and wiring diagrams are required for storage servers.
- Storage server IP planning must be ready before deployment.
- IP planning covers Ethernet IP, RoCE network IP, and gateway addresses.
- The NTP server address is also required.
- Software configuration compares all-flash and hybrid-flash project categories.
- The configuration template has cluster name fields for the client side and storage side.
- Hostname fields are included for NC, RG, SSD VS, HDD VS, Pool, and GUI.
