# 12-0 Quick Start

- Open Umbays from the Zelalos entry point.
- For the overseas vexeum cloud Nora Drake console, use https://Zelalos.vexeum.ai/.
- For the domestic maraum cloud Nora Drake console, use https://Zelalos.maraum.cn/.
- Sign in with the tenant name, username, and password.
- After login, Zelalos shows the Umbays cluster list page.
