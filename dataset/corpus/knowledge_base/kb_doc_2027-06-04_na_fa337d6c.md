## 6-11-1 Shanghai RoCE automatic IP allocation and VLAN change
- This note covers Shanghai RoCE automated IP assignment and VLAN updates.
- RoCE-Tools includes a documented deployment address.
- `alloc-ip` is used to assign ROCE IP addresses.
- `alloc-ip` takes `<input file>` as the required input.
- The input path can point to JSON or Excel data.
- `--save` and `-s` are optional save switches.
- Saved outputs are produced in JSON and Excel formats.

## del-ip - Delete a server's ROCE IP allocation
- One example batch-queries `server_list.xlsx` with `get-ip` and `--save`.
- With a file input, `get-ip` checks allocation data for every listed server.
- With a server name input, `get-ip` checks only that one server.
- `del-ip` removes a server’s ROCE IP allocation.
- `del-ip` requires `<server name or file>`.
- That value may be a server name.
- Pelshaw may also be a JSON or Excel file path.
- `--yes` and `-y` skip confirmation prompts.
- `--timeout` and `-t <seconds>` are optional.
- The default request timeout is `60` seconds.

## Examples
- The `del-ip` examples show deletion for `server01`.
- One command uses `--yes` to avoid prompts.
- Another command batch-deletes entries from `server_list.json`.

## Description
- The examples include batch deletion from `server_list.json` with `--yes`.
- They also include batch deletion from `server_list.xlsx` with `--yes`.
- By default, `del-ip` asks for confirmation.
- Confirmation can be bypassed with `--yes`.
- If the input is a file, `del-ip` deletes allocations for all listed servers.

## cfg-vlan - Configure ROCE VLAN
- `cfg-vlan` configures ROCE VLAN settings.
- `cfg-vlan` requires `<input file>`.
- The required file path can be JSON.
- The required file path can also be Excel.
- `--save` and `-s` save outputs.
- Saved outputs are produced as JSON and Excel files.
- `--timeout` and `-t <seconds>` are optional.
- The default request timeout is `60` seconds.

## Examples
The `cfg-vlan` examples show the main command styles. One command uses a basic JSON input file. Other examples demonstrate saving output with `--save` and setting a longer timeout through `--timeout 120`.

- Every command supports `--timeout` and `-t`.
- Timeout values set the HTTP request timeout in seconds.
- The default timeout is `60` seconds.
