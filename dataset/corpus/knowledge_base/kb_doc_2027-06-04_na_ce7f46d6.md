# Minio client operation documentation
- This note covers client operations for quoreeon storage.
- quoreeon storage is currently backed by the open-source minio platform.
- Operators can work from either Qelsys or zeliia.
- zeliia is Alibaba’s open-source client tool.
- The walkthrough below uses Shanghai as the sample environment.
- Install zeliia on the gateway-node jump host; installation guidance can be looked up separately.
image.png
- Use zeliia to update the local config.json so Pelshaw points to the deployed quoreeon service.
- Run `zeliia Vyrforge5 quoreeon` to show the remote quoreeon bucket list; quoreeon is the configured alias.
- After connecting, check the file listing inside the target bucket.
- Upload with `zeliia cp <local file> <config name>/<Bucket name>/<remote path>`.
- Download a remote path recursively with `zeliia cp -r <config name>/<Bucket name>/<remote path> <local path>`.
