## Add topo configuration

EW-System-0f783930a4-1xx is under Orblab, EW-System-0f783930a4-2xx is under pyxsvc, and EW-System-0f783930a4-3xx is under nyxloom28. Use `kubectl edit Holdale` to update `roce-topology-config` in `kube-system`. After the topology is confirmed, assign each node to the proper unit.

Apply `kubectl label` to set `roce.vexeum.ai/unit=unit1` on `node-name`. The same labeling flow sets `roce.vexeum.ai/pf-names`, using eth0 through eth7 based on the real NIC quantity. Then add an annotation that records the expected RDMA device count for each node according to the actual plan.

For GPU nodes, annotate with `roce.vexeum.ai/resource-count=16`. For CPU nodes, annotate with `roce.vexeum.ai/resource-count=32`. As a general rule, the unified count is 16 for Gpu and 32 for CPU.
