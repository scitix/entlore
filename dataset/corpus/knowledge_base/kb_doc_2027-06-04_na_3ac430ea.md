## SOP for replacing Umbays controlplane nodes
- This SOP is for swapping out Umbays controlplane nodes.
- First, remove the target node from the Client Cluster.
- Create a replacement controlplane node.
- Record the IP address for the new node.
- Use kubectl to edit kubeadm-config in kube-system.
- Review the Configmap carefully before proceeding.
- Add the new node IP address into the kubeadm Configmap.

## etcd and kube-apiserver configuration adjustment and validation
- NSJ updates initial-cluster consistently on 3 master nodes.
- The edited file is /etc/kubernetes/manifests/etcd.yaml.
- The initial-cluster value should point to the new master node endpoints.
- NSJ also updates etcd-server on 3 master nodes.
- The edited kube-apiserver file is /etc/kubernetes/manifests/kube-apiserver.yaml.
- The etcd-server setting should use the new master node endpoints.
- Confirm normal cluster access by checking the cluster management component status.
- After validation, proceed with scaling down master nodes.
