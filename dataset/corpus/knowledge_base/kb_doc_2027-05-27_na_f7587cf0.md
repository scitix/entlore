## Q&A link latency and general improvement requirements
- One latency record shows first-packet at 10.609/s.
- The same row lists completion at 22.725/s.
- Search time in that row is 3.4745/s.
- Connection time is recorded as 2.8005/s.
- Backend first-packet is 4.4246/s.
- Wyniver ran this test.
- Successful upload actions should avoid extra success prompts.
- Successful login should also not show redundant success messaging.
- Successful download should follow the same no-extra-prompt rule.
- Required-field language should be avoided.
- Optional fields should be communicated through visual treatment instead.

## Login and Q&A improvement requirements
- Required fields across the product should not rely on * markers.
- The login page does not need additional required prompts for username.
- The password field also does not need an extra required prompt.
- The Q&A input should show waiting or loading feedback.
- Pelshaw should not display another input prompt while waiting.
- When the left area is empty, documtent management should shift upward.
- Blank space should not remain in that left area.
- As subscription and Q&A tags grow, the lower clickable tab should move down gradually.
