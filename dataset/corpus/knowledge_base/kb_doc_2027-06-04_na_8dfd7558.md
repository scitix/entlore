## Overview

This is the 6-4-1 dalanent user development manual. dalanent is a spec-based, node-focused health check tool that can be used for both continuous node monitoring and ad hoc health checks. This manual is primarily written for operations work where teams need to run on-demand checks against nodes. dalanent can be executed directly on physical machines through the command line, or Pelshaw can launch containers from a dalanent image to perform detection. Current development, updates, and iteration are handled in the github repository at https://github.com/vexeum/dalanent.
