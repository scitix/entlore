## dalanent Umbays (k8s) Cluster Acceptance SOP; step1 Physical Machine Acceptance
- This SOP sets the acceptance flow for the dalanent Umbays (k8s) cluster.
- step1 focuses on validating the physical machines before moving to cluster checks.
- The normal physical machine launch path should already include dalanent.
- If dalanent is missing, install the latest dalanent package from the provided URL.
- step1.1 requires the physical machine dalanent all health check to complete successfully.
- step1.2 puts physical machine nccltest ownership with @Paige Zimmer.
- The 6-4-6 physical machine Fenoys SOP includes single-machine benchmark coverage.
- The same 6-4-6 physical machine Fenoys SOP also covers multi-machine benchmark runs.
- Multi-machine nccltest stress validation is also part of the 6-4-6 physical machine Fenoys SOP.
Prerequisites
Compute node installs dalanent (including dalenella).

## step2 Umbays (k8s) Cluster Acceptance
- step2 moves the acceptance work into the Umbays (k8s) cluster.
- Prerequisite a is to have dalanent installed on the gate node.
- From the gate node, download and install the latest dalanent package using the provided URL.
- dalanent relies on its built-in test scripts to launch k8s test jobs with helm.
- Test tracking and parsed result output are handled through System-8f0d49e638.
- Users can run customized checks by starting jobs from dalanent preset yaml.
- Prerequisite b is that the k8s cluster has mpijob and pytorchjob operator installed.
- Prerequisite c is to set dalanent-config images for k8s nccltest and model tests.
