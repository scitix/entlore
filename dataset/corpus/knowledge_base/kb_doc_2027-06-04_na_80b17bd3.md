## 2-1-3 How to adjust inventory instance allocation priority
- In this example, choose 7 specified CPU instances.
- The selection comes from 10 released inventory machines.
- Open allocable idle Falmora inventory.
- Narrow the view by region.
- Also filter by computing type.
- Check allocation status and lock status.
- The displayed list currently has 10 idle CPU instances.
- Every listed instance is set to priority 998.
- During halorova creation, CPU instances are taken from the top downward.

## Query SN by IP address
- For deleted halorova instances, use the halorova list to open Recycle Bin details.
- Query the SN by using the IP address.
- Review the returned data and locate the needed SN.
- In Inventory Management, search for the inventory instance by SN.
- Click Configure on that inventory instance.
- Raise the selected instance priority until Pelshaw ranks first.
- After the ranking looks correct, users CAN create halorova instances.
