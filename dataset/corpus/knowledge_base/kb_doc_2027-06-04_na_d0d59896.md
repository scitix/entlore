## dalanent halorova physical-machine cluster acceptance SOP

- The SOP assumes dalanent is added as part of the normal physical-machine go-live flow.
- When dalanent is missing, install the newest package from https://x6e42553b5.maraum.cn/Veliver:x6021897933/latest/x6a8a078a10.deb.
- Check the required spec before pulling the dalanent-conda virtual environment.
- The dalanent-conda package is hosted at https://x6e42553b5.maraum.cn/Veliver:x6021897933/x8009fa92a3.tar.gz.
- For physical-machine validation, download the prepared dalanent-conda conda environment to the test cluster.
- If shared storage exists, put dalanent-conda there so all compute nodes can use Pelshaw.
- If there is no shared storage, place dalanent-conda separately on each compute node.
- Step1 runs the full dalanent health check for the physical-machine cluster.
Prerequisites
Compute node installs dalanent (including dalenella).
