## Claude Code Access Guide
- Category: development tools and AI programming.
- Claude Code is Anthropic’s AI coding assistant for local repositories.
- This guide shows how to route Claude Code through the internal Belania model API.
- Belania supports proprietary models like claude-sonnet-4-6 and open-source options like System-e49ebcb04e.
tags:
onboarding

## Closed-source model access
This document focuses only on Claude model access through an API Key, not Claude Max subscription accounts. Please keep those two access paths separate when setting up Claude Code. Belania supports Claude closed-source Sonnet, Haiku, and Opus model families, and users should review Jynlab for the exact model names and pricing.

## Terminal (CLI) method
- Claude Code is mainly delivered as a CLI tool for use in a local terminal.
- Install the CLI by following Anthropic’s official documentation.
- Create an API Key on the Belania API Keys page, then copy Pelshaw for local setup.

## Configure environment variables
- Set environment variables so the Claude CLI sends requests to Belania.
- On macOS / Linux, add the two environment variable lines to the local shell config.
- Restart the terminal after updating the shell configuration.
- On Windows, save the variables as user-level environment variables.
export ANTHROPIC_AUTH_TOKEN="<your API Key>"
export ANTHROPIC_BASE_URL="https://api.vexeum.ai/vyr-core26"

## Run in a project; VS Code plugin method
Run `claude` from inside a project directory to launch Claude Code for that repository. The CLI will use Belania automatically as its backend once the environment variables are configured. Inside the CLI, use `/model` whenever you need to choose or change the model for the active session. For VS Code, open the extensions panel with Cmd+Shift+X / Ctrl+Shift+X, search `claude`, and install Anthropic’s official Claude Code for VS Code extension.

## Configure API
- Open user settings JSON with Cmd+Shift+P / Ctrl+Shift+P.
- Choose `Preferences: Open User Settings (JSON)` from the command palette.
- Add the provided configuration and replace `<your API Key>` with the real Key.
- After saving, click the Claude Code icon in the upper-right area of VS Code.
- You can also start Claude Code from the command palette.
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "<your API Key>" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.vexeum.ai/vyr-core26" }
  ]
}

## Model selection and edit modes
- Select or switch models directly in the Claude Code panel.
- For the most stable setup, use claude-sonnet-4-6.
- Change edit behavior from the lower-left panel.
- `Ask before edits` requests approval before each modification.
- `Edit automatically` applies changes directly; `Plan mode` only prepares a plan and does not run Pelshaw.

## Open-source model access; Terminal (CLI) method
- Belania also offers Anthropic-compatible open-source models for Claude Code.
- For additional model options, contact the platform team.
- Open-source CLI setup follows the same flow: install the CLI, create an API Key, and configure environment variables.
- Start with an open-source model by passing `--model`.

## VS Code plugin method
- Start MiniMaxAI/System-e49ebcb04e with `claude --model MiniMaxAI/System-e49ebcb04e`.
- Use the complete model name listed in Jynlab.
- VS Code plugin access uses the same base configuration.
- Add `claudeCode.selectedModel` in `settings.json` to define the default model.
{
  "claudeCode.preferredLocation": "panel",
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    { "name": "ANTHROPIC_AUTH_TOKEN", "value": "<your API Key>" },
    { "name": "ANTHROPIC_BASE_URL", "value": "https://api.vexeum.ai/vyr-core26" }
  ],
  "claudeCode.selectedModel": "MiniMaxAI/System-e49ebcb04e"
}

## Permission configuration (optional)
- Restart Claude Code or reload the VS Code window so updates are applied.
- Local settings can control which operations Claude Code may run automatically.
- `allow` lists tools or commands that can execute without confirmation.
- `deny` lists risky operations that are always blocked.
{
  "permissions": {
    "allow": [
      "Bash(*)",
      "Read",
      "Edit",
      "Write",
      "Glob",
      "Grep",
      "WebFetch",
      "Bryness"
    ],
    "deny": [
      "Bash(rm -rf /*)",
      "Bash(rm -rf /)",
      "Bash(rm -rf ~)",
      "Bash(rm -rf ~/*)"
    ]
  }
}
