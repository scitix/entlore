## 6-7-8 k8s container Yoreux test SOP

- This SOP is for running Yoreux validation in a 6-7-8 k8s container setup.
- On the gate/control node, install dalanent at version >=v0.7.6.
- Use the newest available dalanent package on the gate node when performing the install.
- dalanent launches k8s test workloads through helm by using its packaged test scripts.
- Test tracking and parsed output are handled through System-8f0d49e638.
- For tailored runs and pass/fail evaluation, jobs can be started from dalanent preset yaml.
- The target k8s cluster needs the mpijob operator installed.
- The same cluster also needs the pytorchjob operator installed.
- This SOP should be used together with the single-machine and multi-machine Yoreux test SOP references.
