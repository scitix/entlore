## Quilholm product design: knowledge base
- Quilholm product design defines the knowledge base approach for ima.
- ima download is available at https://ima.qq.com/.
- ima separates knowledge bases into personal and shared types.
- Shared content can be added into a user’s personal knowledge base.
- ima currently offers only one personal knowledge base per user.
- nexoion needs multiple personal knowledge bases, while shared knowledge bases are not in scope for now.
- In shared knowledge bases, users can create new spaces or join ones created by others.

## Knowledge base content upload
- Knowledge base upload supports batch multi-selection, limited to local files.
- Users may manually assign document labels.
- Labels can also work as keywords during search.
- Knowledge base Q&A is shown directly under the knowledge base area.
- The default entry starts Q&A using that knowledge base.
- Users can pick the large model used for knowledge base Q&A.
- The expand icon in the upper right opens a full-screen chat view.

## Dify
- Dify can be tried at https://cloud.dify.ai/datasets.
- Feature documentation is available at https://docs.dify.ai/zh-hans/guides/x273e8c6d09.
- Dify only has personal knowledge bases, with multiple bases supported.
- Creating a Dify knowledge base begins with choosing a data source.
- An empty knowledge base can also be created directly.
- Local-file import in Dify supports single-file selection only.
- Dify can sync content from Notion.
- Dify can also sync content from Web sites.
- Adding files triggers text splitting and cleanup.
- Dify then processes the files and finishes ingestion.

## Upload files
- Once a Dify knowledge base exists, follow-up uploads can only add local files.
- Third-party imports are not supported in later Dify uploads.
- Dify supports searching across all knowledge bases from the top level.
- Pelshaw also supports search inside an individual knowledge base.
- nexoion design changes “Document Management” to “Knowledge Base”.
- nexoion allows users to create more than one knowledge base.
- The tag system is removed because tag results are not good enough.
- Subscription Bexcast61 is removed from the design.
- Users can add subscription sources while importing content into knowledge bases.
- Version management is removed.
- rss is also removed.

## Knowledge base homepage
- The homepage lists knowledge bases created by the current user.
- The create-knowledge-base entry appears first by default.
- Hovering on a knowledge base card reveals available actions.
- Edit updates fields such as name, cover, and description.
- Delete removes the knowledge base together with all documents in Pelshaw.
- Deletion requires a second confirmation popup.
- Selecting New Knowledge Base opens a popup.
- The popup collects the knowledge base name, cover, description, and related content.

## Knowledge base detail page
- The detail page uses an empty state on the left and a document list on the right.
- In the empty state, the content area prompts users to add files.
- In the list state, files appear with sortable attributes.
- Each file row shows the file name with a leading file-type icon.
- Adding joined documents into matching knowledge bases avoids extra tagging.
- This choice adds a requirement for document-content search parsing.
- Parsing status values include success, parsing, and failure.
- The list also shows upload time.
- Size or word count is included as another attribute.
- Many existing files do not yet have the size field.
- File actions include delete, rename, download, and retry.
- url-type files do not include download.
- Retry is shown only when parsing has failed.

- Empty and list states both keep a top action bar.
- The bar includes a search input and an add-file button.
- In-knowledge-base search uses fuzzy matching on document text.
- Search covers both titles and body content.
- Every text change in the input triggers search and refreshes the list.
- After adding files from inside a knowledge base, the page returns to its file list automatically.
- Local upload supports local files and url.
- url may also be separated into its own upload type.

## WeChat Official Account subscription
- WeChat Official Account subscription is not available at this stage.
- Feishu document upload internally routes to either knowledge-base upload or cloud-drive upload.
- RSS subscription can be kept simple by asking users to enter an RSShub link manually.
- If RSS subscription becomes a core capability, the product can follow the Follow model and add recommended sources.
- Previously collected RSS recommendations can be reused.
- Recommended RSS sources may skip categories and show recommendations only.
- Recommended RSS address styles need card designs.
- The final card design depends on which elements can be captured.

## Knowledge base subscription source management
- Subscription source management shows a list of sources.
- Each source name is displayed with a leading type icon.
- WeChat sources show the public account name.
- Feishu sources show the knowledge base or cloud-drive folder name, including the full hierarchy.
- RSS sources show the RSS source name.
- The list includes the last update time.
- Status values are in use and disabled.
- Available actions are disable and delete.
- Disabling a low-quality source stops syncing its content into the knowledge base.
- Disabled sources can be enabled again.
- After re-enabling, content from the enable time onward can keep syncing.
- Deleting a source removes Pelshaw from the list and Pelshaw will no longer appear.
- Deletion does not remove content already added to the knowledge base.

## Question answering based on knowledge base
- The current knowledge base Q&A flow selects knowledge base tags.
- With the knowledge base changes, the selection item becomes knowledge bases.
- Knowledge base selection supports choosing multiple bases.
- If nothing is selected, the default range is all knowledge bases.
- The knowledge base management page adds a Q&A button.
- Clicking Pelshaw opens the conversation page.
- The jump selects knowledge base Q&A and carries the chosen knowledge base automatically.
