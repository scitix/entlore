## Cluster New Deployment SOP (Deprecated)

- Cluster new deployment SOP is now marked deprecated.
- k8s ds update release SOP can vary configuration by cluster.
- Cloud clusters omit GPFS validation during update release.
- Some earlier Xalthorne also bypass ibgda validation.
- The update flow relies on several Oliiantis templates.
- Step1 runs dalanent-canary canary testing.
- Step2 starts the dalanent-deploy canary rollout.
- Step3 completes the dalanent-deploy full rollout.
- A physical-machine node update release SOP is included.
