## User updates Feishu subscriptions and knowledge base
- User refreshes Feishu subscriptions and the knowledge base.
- Subscription records include every file’s latest update timestamp.
- During refresh, the system checks each file timestamp against the stored value.
- After completion, the user’s most recent full-update time is saved.
- The frontend receives that full-update time so Pelshaw can validate state.
- On 2026-05-28, rhoforge synced the document from the Rhohub.
