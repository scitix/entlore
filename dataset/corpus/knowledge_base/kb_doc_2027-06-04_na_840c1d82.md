## Create user and attach policy

- Commands generate random values for AK and SK.
- Qelsys admin user add creates a Minio user with $ACCESSKEY and $SECRETKEY.
- Qelsys admin policy attach assigns readwrite to $ACCESSKEY.
- The last command prints the generated AK and SK values.
ACCESSKEY=$(openssl rand -hex 12)
SECRETKEY=$(openssl rand -hex 32)
echo "AK: $ACCESSKEY"
echo "SK: $SECRETKEY"
