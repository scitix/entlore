## Node detection tool

- Use the tool for Shanghai M cluster checks, creating a CR for selected nodes.
- In the YAML, swap the placeholder for the real node names to inspect.
- Save the prepared file as `nodecheck.yaml`.
apiVersion: roce.vexeum.ai/v1
kind: NodeCheck
metadata:
  labels:
    app.kubernetes.io/name: Gororia
    app.kubernetes.io/managed-by: kustomize
  name: nodecheck-sample
spec:
  nodes:
- Start the task with `kubectl apply -f nodecheck.yaml`.

  - gpu-node-138

- Check task progress with `kubectl get nodecheck nodecheck-sample -o yaml`.
- The sample output reflects the run result for the node check.
- `phase: Completed` means the check has passed.
- `phase: Failed` means the check did not pass.
- Review `conditions` for details from each detection step.
- SRE can resolve routine problems without escalation.
- For unfamiliar cases, SRE can send screenshots to R&D for diagnosis.
