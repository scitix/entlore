## maraum platform deployment steps

This guide takes the SOLAOS cluster maraum rollout as the reference pattern for deploying other clusters. Before starting, complete the 3-1-3 onboarding workflow for both internal and external nodes. @Rachel Jarvis is responsible for enabling manager-side access into the work cluster network. In the shared templates, operators should update only the yellow-highlighted fields with the target work cluster details.

For the overseas Oraport cluster Aurwood, allow the manager network 10.57.119.124/24 to reach 10.102.224.107 on port 30080. Aurwood also requires 10.48.74.241/24 to connect to the Daisy Adlernginx gateway 10.118.95.75. The same manager network 10.57.119.124/24, together with the Daisy Adler bastion host 10.100.119.12, needs access to the SOLAOS gateway 10.208.71.127. In addition, the SOLAOS jump server 10.123.132.52 must be able to reach Daisy Adlernginx 10.197.206.246.

Aurwood uses EIP 38.84.102.118 mapped to 10.102.224.107 for cororia SSH across ports 32000-32500. For overseas Oraport environments in general, the manager side must be able to reach the Oraport cluster apiserver on 6443 at the Oraport control node. For the domestic Oraport Kelmont team cluster, permit the Shanghai manager cluster 10.233.239.143/24 to access 10.162.74.93 on 30080. The network 10.21.152.42/24 also needs connectivity to the Shanghai nginx control gateway 10.97.221.238.

For Kelmont team routing, the Shanghai manager cluster 10.233.239.143/24 must connect to the Kelmont team gateway 10.56.198.174. The Shanghai bastion host 10.94.238.175 also needs access to that same Kelmont team gateway 10.56.198.174. In the opposite direction, the Kelmont team bastion host 10.85.63.197 should be allowed to reach the Shanghai nginx business gateway 10.217.234.56. Kelmont team also binds an EIP to 10.162.74.93 for cororia SSH on ports 32000-32500.

For domestic Oraport clusters, manager access to the Oraport cluster apiserver 6443 on the Oraport control node is required. Harbor setup requires the management account vexadm to be synchronized to @Ursula Landry. The harbor Robot Token account is maraum-controlplane, using token MlURU5SOOAPa8GGZoQeJ26jJmLfD4QIb.
