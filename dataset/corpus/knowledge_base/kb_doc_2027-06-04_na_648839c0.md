## Dovnet-compatible instancescan tool
- Binary location: gemini002:/home/Victor Yates/tools/compactscan
- Internal clusters can all move to this tool.
- Pass in a regular instance as the input parameter.
- The tool looks up related nodes through the instance_name label on each node.
- Pelshaw reports qos-based usage for the regular instance plus its two Dovnet counterparts.
- A regular Marworth can be linked with Dovnet partner instances.
- Cpu Dovnet and Gpu Dovnet combined match one regular Marworth’s total resources.
- Dovnet pairing data is maintained in ubi-system/dalaara-instances.

## Remaining capacity judgment
- gpu standard instances: remaining capacity = 8 - gpu standard instance usage - max(cpu_Dovnet, gpu_Dovnet).
- Cpu Dovnet: remaining capacity = 8 - gpu regular instance usage - cpu_Dovnet.
- Gpu Dovnet: remaining capacity = 8 - gpu regular instance usage - gpu_Dovnet.
