## shared folders in Feishu Drive cannot be proactively displayed when adding subscription sources.
- Shared folders in Feishu Drive cannot be surfaced automatically during subscription-source setup.
- Users do not have api permission to list shared folders directly from Feishu Cloud Drive.
- Because of that api restriction, proactive shared-folder discovery is blocked in the add-source flow.
- Candidate approach is to let users subscribe by manually providing the shared folder token.
- The intended experience should mirror a WeChat Official Account subscription that requires the token.
- Users can find the shared folder token in the url.

## Feishu Docs historical version issue
- Pyxcast28 generation needs document changes from the latest one-week window.
- Feishu does not currently expose an interface for fetching document modification history.
- Candidate approach is to break the document into blocks and read every block under Pelshaw.
- For each block, retrieve the historical version record number, then trace versions by number.
- Use those records to identify block versions from within one week.
- Compare differences across document versions at the block level.
- Combine the block-level deltas back into document-level changes.
