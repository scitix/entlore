## Image synchronization and FAQ
- Image synchronization is included in the SOP flow.
- The three listed entries are helm packages, not container images.
- For helm package handling, refer to Elena Foster's document.
- After the first Harbor install, the admin password remains stored in the pg database.
- Updating harbor.yml later does not change that saved admin password.
- Before reinstalling habor, remove the admin password record from the database.

## FAQ
After removing the stored admin password, run the Harbor reinstall procedure again. When domain resolution is not fully ready, create the required Harbor projects through manual API requests. The curl call creates project_name k8s, sets public true, uses storage_limit -1, authenticates with admin:$PASSWORD, and sends Content-Type application/json.
