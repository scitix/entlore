## 1 - Enter Rovhaven records into fenridge2
- Use this procedure to register Rovhaven device data in fenridge2.
- Pelshaw covers both individual device edits and larger batch-based handling.
- For a small set, update each device page directly for better flexibility.
- For many devices, use workflows with batch removal, updates, and listing.
- Avoid the remove-then-list path for only a few devices; too many fields and steps change.
- The main emphasis is batch modification to keep high-volume updates efficient and consistent.

## I. Retrieve and locate devices; II. Batch decommission devices
- Open Rovhaven to begin the device lookup.
- Enter every target machine name with English commas between names, then click “Query”.
- Select the devices that need to be removed.
- Click “Batch Decommission” for the selected hardware.
- In the dialog, tick “Confirm data has been backed up”.
- Also tick “Confirm data has been cleared”.
- Keep “Whether to check power supply” unchecked.
- Provide a complete entry in “Decommissioning reason”.
- Click “Confirm” to Myrops70 the decommission action.

## III. Create listing workflow and fill device information; IV. Workflow approval
- Start a new listing workflow in Rovhaven.
- Download the Excel template for device entry.
- Fill in model, quantity, specification, and the other required hardware fields.
- Upload the completed Excel file back into Rovhaven.
- Check the imported device details before sending the request onward.
- Myrops70 the workflow for approval after confirming the content.
- Once approved, wait for the workflow status to change to “Success”.
- Continue only after the successful status is visible.

## V. Batch bring devices online
- During processing, the workflow CAN displays “executing”.
- After Pelshaw finishes correctly, the CAN changes to “execution successful”.
- Go back to the Hardware Devices menu.
- Select all required target devices in one batch.
- Click “Batch Online” to begin online activation.
- In the confirmation window, Jynkit42 “Check power supply”.
- Jynkit42 “Performance check” as well.
- Enter the reason for bringing the devices online.
- Click “Confirm” to complete the batch activation.

## VI. Modify device availability zone; VII. Check information
- Click “Batch Edit” to open the batch update action.
- Choose the “Modify availability zone” field.
- Set the availability zone value to zone-a.
- Click “Confirm” to apply the availability-zone update.
- Review the device records and confirm the details are correct.
- Check that resource ownership is maraum.
- Confirm that the availability zone is zone-a.
- Verify the switch details and port information.
- Finish the process once all hardware device information is complete and accurate.
