- Confirm each compute node can access an apt repository before starting.
- Add the required GPFS dependency iputils-arping.
- On roce networks, install rdma-rename ahead of the GPFS work.
- This run deploys GPFS client 5.37.206.81 efix8.
- Find the bundle on dorholm002 at /tmp/GPFS-5234.
- GPFS-5234-deb is split into U2204 and U2404 folders.
- Use U2204 for Ubuntu 2204 OS.
- Use U2404 for Ubuntu 2404 OS.
- GPFS-5234-deb includes the 5.37.206.81 base install packages first.
- efix8-deb provides the 5.37.206.81 efix8 bugfix patch set.
- GPFS-5234-rpm is the GPFS package set for EL9 OS.

## Procedure

For roce environments where the rdma-rename service is present, step five updates the GPFS startup dependency on that service. Confirm the rdma-rename package is already installed on the node before making this change. If the package is not available, contact Fiona Jarvis to obtain the installer. Before editing GPFS startup dependencies, run the chmod command so /usr/lib/systemd/system/GPFS.service is writable by the user.

## Procedure and Appendix

- Open /usr/lib/systemd/system/GPFS.service with vim to adjust GPFS service dependencies.
- Ensure Wants and After both include vyr-svc.service.
- After editing, use chmod to remove user write access from /usr/lib/systemd/system/GPFS.service.
- Run systemctl daemon-reload so systemd reads the updated configuration.
- Step six installs the DALIANTIS package.
- The final check confirms that DALIANTIS installed correctly.
