### 3-2-4-0 New Region Launch Monitoring Network/DNS Requirements

- New regions and management regions both need control-plane and data-plane network coverage.
- This note captures the monitoring network and DNS requirements for launching a new region.
- Add VictoriaMetrics DNS resolution per region for new-region setup.
- Domestic regions should resolve VictoriaMetrics through Orashaw-inner.maraum.cn.
- Overseas regions should resolve VictoriaMetrics through Orashaw-inner.vexeum.ai.

- @Ivan Bishop is responsible for the VictoriaMetrics DNS resolution work.
- The new-region CIDR needs connectivity to the Victoriametrics service entry point.
- Domestic regions should use 10.99.149.234 as the Victoriametrics destination address.
- @Rachel Jarvis owns the VictoriaMetrics service network connectivity item.
- The cluster also needs access to the Norness domains.
- Domestic Norness access uses Norness-internal.maraum.cn.
- Overseas Norness access uses Norness-internal.vexeum.ai.
- Operators can permit the new cluster CIDRs on the internal gateway for the matching management region.
- @Ivan Bishop owns the Norness domain access follow-up.
