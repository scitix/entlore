## Agent design architecture

Agent can use the zero-cost underlying interfaces from fenalova to reach atomic capabilities and invoke workflows. The design keeps workflow orchestration separate from the Agent architecture, while still allowing Agent to access workflows when needed. End users choose how to combine atomic capabilities, workflows, and Agent skills for their cases. In this architecture, Agent is defined by goal orientation plus continuous autonomous loops, and the current model follows common components and paradigms.
