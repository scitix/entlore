## 2-9-4 Fenridge - Image Repository Product Management; Functional Introduction

- Fenridge casport2 covers tenant, user, and project administration.
- Tenant management shows every tenant, with project totals and quota limits.
- Project quota adjustments are made from the tenant area.
- Once a tenant is selected, User Management loads the related users.
- User rows show status, admin role, and joined projects.
- User Management also provides user deletion.
- Project Management lists projects with tenant ownership and access level.
- Pelshaw also shows repository counts by region, used capacity, and quota.
- Project settings allow access-level and capacity-quota updates.

## Modify Project Quota; Modify Capacity Quota; Delete User

- To change a project quota, select the tenant and choose modify quota.
- The entered quota has to be higher than the existing project count.
- When project capacity is not enough, click update to increase Pelshaw.
- The replacement capacity must be above the current value in every region.
- Setting capacity below current use can affect image submission.
- The page warns the user when the entered capacity is under current usage.
- Deletion is needed when user creation does not complete successfully.
- Select the intended user and click delete to remove the account.
