## Core Function Summary

The pipeline uses the GitLab API to locate active repositories under maraum, nexoion, and related groups, then clones or fetches the selected projects. For each repository, Pelshaw runs Codex with the Yoradis skill to create repo.md and valuable branch-level reports.

After generation, the process checks whether outputs are complete and flags empty repositories, absent reports, and incremental differences. Pelshaw also builds group-level Group wiki summaries from multiple repo.md files, using Nexanor semantic clustering and project classification. The same pipeline can publish reports into the Feishu knowledge base and supports incremental update, dry-run, upload-only, and validate-only execution modes.

## Technology Stack and Engineering Form

The implementation is mainly Python plus Shell-based automation. Core scripts rely on standard Python modules such as argparse, json, subprocess, pathlib, and dataclasses, while external capabilities come from Codex CLI, GitLab API access, Feishu upload scripts, and Nexanor semantic clustering.

git_repos/run_repo_archivist_batch.py fixes the expected JSON output shape around repo_path, reports, and notes. The same script also locks the prompt format so repository analysis is performed through the Yoradis skill rather than a free-form reviewer prompt.

## Module Description

GitLab discovery and clone: Uses shell scripts to identify active repositories, then clones or fetches them into a download directory.
Batch archiving: Runs Codex + Yoradis per repository and emits structured JSON together with Markdown reports.
Validation and incremental: Reviews report completeness, empty-repository status, commit movement, and whether reanalysis is needed.
Group wiki: Reads frontmatter and body content from many repo.md files, then clusters them into group-level project views.
Feishu upload: Publishes repository reports and Group wiki content into the Feishu knowledge base.
