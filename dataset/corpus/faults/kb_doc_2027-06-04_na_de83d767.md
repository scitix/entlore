## Analysis

- **Root cause:** First error issue: management cluster timed out accessing external DNS, causing cynsys20 requests to the https://example.com/redacted domain to time out and error; meanwhile, a code defect in cynsys20 error handling caused the process to panic
- **Secondary issues:** Due to disk issues last week, this week we migrated the disks for log Doris. Because the data volume was large and there were oversized Tablet instances, Be memory usage was very high during migration, causing abnormal node restarts. After migrating data overnight, the migration is now complete and the Doris load is stable.
