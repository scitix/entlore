## Incident Description

- **Time:** 2027-03-12
- **Reporter:** Vince Parker
- **System:** Halorova
- **Symptom:** Two machines of an external user were compromised due to githubpublic permission issues
- **Impact scope:** 2 bare-metal machines

## Analysis

- **Root cause:** User usage issue.
- **Secondary issues:** TBD

## Handling

- **Handlers:** Xander Grant, Luna Holt
- **Steps:**

Incident Summary
----------------
A malicious modification was introduced in the following pull request:
[test] Fix function in test_mimo_models · Pull Request #20423 · sgl-project/sglang
The change added binary code which was executed on internal machines.

Affected Machines
-----------------
10.66.53.7
10.66.53.8

Immediate Actions Taken
-----------------------
1. Both machines were shut down through BMC to prevent further activity.

2. Machine 10.66.53.8
   - OS has been reinstalled to restore the machine to a clean state.

3. Machine 10.66.53.7
   - Kept offline for forensic investigation.
   - Objective: verify whether the executed binary attempted or succeeded in accessing other servers.
