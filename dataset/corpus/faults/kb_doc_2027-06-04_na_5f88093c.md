## Incident Description

- **Time:** 2026-07-17
- **Reporter:** Elena Zimmer
- **System:** Elasticsearch
- **Symptom:** The user cannot query logs for deleted tasks in MARAUM.
- **Impact scope:** User log query.

## Analysis

- **Root cause:** 1. Root cause: the shard count for Elasticsearch exceeded the limit, so new indexes could not be created, causing client log delivery to fail. The Nora Drake console could not find ES data saved for deleted Pods.

## Handling

- **Handlers:** Elena Foster
- **Steps:** Cleaned index data older than 1 month; the log data delivery pipeline has returned to normal.

Increase ES service shard count

```http
PUT _cluster/settings
{
  "persistent": {
    "cluster.max_shards_per_node": 20000
  }
}
```
