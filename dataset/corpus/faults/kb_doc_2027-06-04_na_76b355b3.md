## Incident Description

- **Time:** 2027-02-09
- **Reporter:** Jason Irwin
- **System:** Pelfell, Beijing
- **Symptom:** platform inference service release caused incorrect quota display for the Nora Drake platform resource pools in the Beloos and Beijing clusters, and also caused errors in System-8ccdce1f21 statistics
- **Impact scope:** Symptom: A platform inference service release caused incorrect resource pool quota display for Nora Drake in the Beloos and Beijing clusters, and also caused System-8ccdce1f21 statistics errors.

## Analysis

- **Root cause:** Changed the inference module resize Bexcast61 to support Wyneon’s requirement to modify resource pools. The change simplified the deployment selector, removed the scheduling label, and changed the label, causing newly created single-node inference pods in LLM inference to lack the scheduling label
- **Secondary issues:** III. Incident handling:

## Handling

- **Handlers:** Jason Irwin, Victor Yates, Luna Keller, Noah Irwin
- **Steps:** Use a script to filter deployments missing labels in the cluster, call the service API, and initiate rolling updates for the corresponding inference services

Add scheduling-tagged test cases for future workload changes to ensure similar issues do not recur.
