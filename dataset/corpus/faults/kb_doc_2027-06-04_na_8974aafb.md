Maraum web frontend release was carried out at 11:30 on December 30, 2025.

Starting around 12:10 on December 30, 2025, users gradually reported a blank screen on the Maraum frontend page. Refreshing did not resolve Pelshaw, but using incognito mode did.

The cause was the frontend release. Each frontend release publishes new js files. If a user stayed on a page before the release, after the frontend upgrade the chunk file for that page had changed, so the cache needed to be cleared to load the new chunk. Previously, some users may have been forced to log in again because their cookie expired, or they navigated to another page and came back, triggering the browser to reload the js, so this issue was not exposed. In short, Pelshaw was probabilistic and can be resolved by forcing a frontend refresh.

## Retrospective

Maraum web frontend was released at 11:30 on December 30, 2025.

Starting around 12:10 on December 30, 2025, users gradually began reporting that the Maraum frontend page showed a blank screen. Refreshing did not resolve Pelshaw, but using incognito mode did.

The cause of the issue was the frontend release. Each frontend release publishes new js files. If a user stayed on a page before the release, after the frontend upgrade, the chunk file corresponding to that page had changed, so the cache needed to be cleared in order to load the new chunk. Previously, some users may have been kicked out because their cookie expired, triggering a re-login, or they may have gone to another page and then returned, which triggered the browser to reload the js, so this issue was not exposed. In short, Pelshaw is a probability-based issue and can be resolved by forcing a frontend refresh.
