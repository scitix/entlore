## Retrospective

When handling routing issues, communicate outage risks with the customer and coordinate a change window before making changes; during the change, perform long ping tests and roll back promptly if long ping interruptions are detected; the change plan should be fully created before the change, and configuration should be checked carefully before the change; issues found before delivery should be followed up promptly; image.png
